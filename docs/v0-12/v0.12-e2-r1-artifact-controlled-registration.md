## Metadata and two registry layers

Reuse E1 `register_artifact`, `config_snapshot`, `save_registry` and inference.
Runtime training manifest is `digest(training_identity)`; runtime config hash is
`digest(config_snapshot(model))`, separately for each artifact. These are derived
metadata, not values falsely claimed present in the old schema. Cutoff 2024-04-15
is derived from the frozen training business window. Historical code SHA comes
from the immutable artifact, never replaced with the current integration SHA.

Delivery execution-contract JSON equals the repository frozen configuration JSON,
but their formatting file hashes differ. The original configuration file hash
is independently verified; it is not substituted for the runtime config hash.

inactive and not content verified. A separate local registry holds verified,
active-for-research entries and local artifact paths; it is not committed.

## Executed engineering acceptance

Original artifacts were loaded in four fresh guarded processes (twice per artifact).
`fit()` is disabled before prediction. Candidate's total, single/7-day peaks and
result hash exactly reproduce the public 736-mu, 2026–2027 TEST_ONLY example.
Using the verified original registry, fresh guarded CLI processes executed
registration, TEST_ONLY issue, verify-seal and REAL_PROSPECTIVE rejection.
No actual import or scientific scoring was performed (`SCIENTIFIC_SCORE_ROLE=NONE`).
The clock is explicitly synthetic TEST_NOT_PROSPECTIVE, not backdated real issuance.
Original file SHA256, size and mtime remained unchanged after the complete chain.

36 synthetic E2 cases and 45 E1 regression cases pass. 34 E2 case units contain
rejection assertions; some contain multiple failure injections. Covered boundaries
include both file/self hashes, IDs, swapped families, roles, training scope/count/area,
identity/config/parameter/curve mismatch, public authority corruption, unverified
registry use, overwrite/atomic failure, post-registration tamper and real-mode refusal.
Tests substitute pinned authority only in-process for hand-specified fixtures;
there is no CLI bypass and no CI dependency on private artifact files.

The related area-yield/S0/S1 regression suite passed: 846 passed, 7 skipped.
Mypy checks backend/app and the new registration tests/replay (522 source files).

Internal wiring fixes were confined to verification: contract file-format identity
was distinguished from JSON equality, and the replay used the existing singular
`prediction` record key. Failed new TEST_ONLY output directories were retained;
no existing record or artifact was overwritten. Final accepted run uses a new directory.
CI and the final Head are recorded outside the self-referential committed evidence.

## Scientific and future boundary

Single-fold amplitude gain remains previously observed, temporal-shape gain false,
stable gain false and new blind validation false. E2 does not independently rebuild
workbooks, prove original source authority, restore a historical runner or improve
the model. Local clock/hash integrity is not trusted external time or administrator-proof storage.
Area interpolation is not validated accuracy.

S2 still requires separately authorized new information or a legitimate future
request with frozen source/area/window/model identity, followed by complete actuals
and locked evaluation. Real issuance is disabled; business acceptance thresholds,
prospective accuracy, probability calibration and production approval are unestablished.
V0.12 remains incomplete. No Ready, Merge, tag, release or deployment is authorized.
