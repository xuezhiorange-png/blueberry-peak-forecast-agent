## 可运行命令与请求

从仓库根目录、已安装项目依赖的环境运行：

```sh
python -m scripts.replay_v0_12_e1 --output-dir /tmp/my-new-e1-TEST_ONLY-run
python -m backend.app.area_yield.prospective_validation_cli v0-12-research --help
```

replay 的输出目录必须尚不存在，既有结果不会被覆盖。它生成显式的公共 synthetic request、
授权来源、手工参数工件和实际来源；不训练、不访问真实数据。
具体 `issue / verify-seal / import-actuals / create-snapshot / evaluate / show-run` 命令、
输出 record ID 与退出码保存在该目录 `replay-result.json`，不是未实现的示意入口。

请求 schema 为 `ProspectiveRequest`：request_id/mode/requested_at、target_area_mu、
target_season、Base/Farm context、窗口、candidate ID/artifact/config hash、comparator ID/hash、
source ID/version/hash、authorization ID/status；字段严格校验，未知字段拒绝。
亩数必须正、精度不超过六位；产季格式 YYYY-YYYY 且后一年度相差1。
完整业务窗口只能是7月1日至次年4月15日，不将全窗口总量挤压进剩余窗口。
请求源是精确 request source payload 的 JSON 文件，hash 与内容均核验；
本地授权是精确 request hash 绑定的 TEST_ONLY operator record。
内容核验不等于业务事实独立核实。

真实模式始终拒绝 `REAL_PROSPECTIVE_NOT_AUTHORIZED`，即使调用者写 REAL_PROSPECTIVE 授权。
started_at、prediction_generated_at、sealed_at/issued_at 分开；推理形成后和持久化完成后
重新检查截止。开始合法而完成越界时只能留下 ABORTED_NOT_ISSUED，不留下可读取有效 seal。
测试时钟始终标 TEST_NOT_PROSPECTIVE；不对外发报，不触发生产动作。

## Artifact registry 与真实身份边界

`register_artifact(model_path, metadata)` 核验既有 artifact 内容及文件 hash、config snapshot、
role、训练支持范围、cutoff、training manifest 身份；`save_registry` 创建不可覆盖的 registry。
发行显式绑定 registry file hash，不按最新文件、SELECTED 字符或版本号选模型。
caller 的模型角色必须为 RESEARCH_CANDIDATE，comparator 为 COMPARATOR_BASELINE，均为
RESEARCH_ONLY、production_approved=false。真正 scoring 不加载 artifact，也不再调用 predict。

当前真实 R1 的公共身份另保留在
`configs/v0_12_e1_reported_artifact_registry.json`：
candidate `NEXT_AREA_SIZE_20261002_R1_CANDIDATE`；comparator registry ID
`V0_12_COMPARATOR_BASELINE` 映射原 baseline ID，不修改旧工件。
没有读取私有模型；只知道公开 artifact/file hashes 的条目设 content_verified=false、
active_for_research=false。未知 manifest/config 内容 hash 用 null，不伪造，也不把配置文件
hash 当模型参数 hash。该声明 registry 无法发行，未来须提供既有工件并核验注册。
synthetic 验收使用独立 `SYNTHETIC_*_NOT_R1_ARTIFACT` 身份，零拟合样本、手工参数，
绝不声称是 R1 的重新训练或真实 R1 工件重放。

面积支持范围216–2548亩作为既有声明保留。每个输出记录 INTERPOLATION/EXTRAPOLATION；
范围内不代表精度有效，范围外 synthetic 允许带 `AREA_EXTRAPOLATION_NOT_VALIDATED` 警示。
真实范围外发行政策留待 S2，当前所有真实发行均拒绝。这与“失败注入均 fail closed”不冲突：
外推的合法 TEST_ONLY 路径是带显式警示，不是自动 production approval。

## Actual、snapshot 与 locked scoring

实际合同保存 revision ID、forecast ID、Base、season、business_date、quantity_status、
new_quantity_kg、来源 ID/version/hash、normalization_version、first_seen_at、recorded_at、
parent/supersedes/revision reason；精确来源 JSON 内容与 hash 均核验。
OBSERVED/AUTHORIZED_ZERO/MISSING 分开，MISSING 只能是 null，不能自动转零。
精度为0.000001kg，超精度拒绝（不先截断峰值再保留小数总量）；尾随零数值等价可规范化。
同源同版本不同内容拒绝，新版本必须明确修订。所有实际导入仅 TEST_ONLY。

E1 使用最小“一个全替换 revision 构成一个 snapshot”规则，不隐式合并冲突日期；
可保留 partial revision，但缺日、MISSING 或窗口未结束只生成 INTERIM_SNAPSHOT，不能最终评分。
最终评分接收 seal ID、snapshot ID、metric contract，校验 implementation/specification hash、
forecast/actual lineage、Base/season/window 与结束时间。只读封存预测+封存 actual；
不 retrain、retune、换候选、换 comparator、改面积、改窗口或改日曲线。
旧实现不可用时明确拒绝，不静默使用最新评分规则。

总量绝对/相对/WAPE、daily MAE/WAPE/SMAPE、单日峰日期/数量绝对及相对误差、
完整连续七日累计峰的起日/量误差均保存。复用旧 canonical 点指标、shape 与分位日期评分；
SMAPE 为逐日 `2|actual-predicted|/(actual+predicted)` 均值，双零贡献0，比例单位为0–2。
真实总量为0时相对指标为 null，不添加 epsilon。并列峰按最早日期，不拼接缺日、不计算7日日均。
同一 actual snapshot 上同时给 candidate/comparator 及候选减基线差值，没有科学阈值。
stable_gain_decision 始终 NOT_EXECUTED；只预留未来四种 decision schema。
business_acceptance_policy_id=null，BUSINESS_ACCURACY_THRESHOLD_STATUS=NOT_ESTABLISHED。
