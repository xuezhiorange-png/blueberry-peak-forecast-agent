## Read contract and selection

One reusable application service composes typed read models; transport contains no prediction mathematics. Six GET-only endpoints live under `/api/v1/forecast-intelligence`: `/overview`, `/curve`, `/hierarchy`, `/uncertainty`, `/attribution`, `/quality`.

Forecast endpoints require explicit source_kind (OPERATIONAL_PEAK or HIERARCHICAL), forecast_family, run_id, hierarchy_level, entity_id, target_season, origin_date, baseline_id, policy_version. Optional expected_source_result_hash is an optimistic authority pin. BASE requires OPERATIONAL_PEAK; REGION/COMPANY require HIERARCHICAL. Unsupported family or mismatched scope returns AUTHORITY_MISMATCH; invalid syntax returns 422. No latest selection, history pagination or cursor is exposed in R1: unexpected/oversized query fields are rejected. IDs are positive bounded integers; identifiers and hashes are bounded/validated. Reruns are selected explicitly and retain lineage, never mixed with parents.

Response carries schema_version, capability, status, forecast_identity/hierarchy_identity/authority_identity where applicable, source_kind, source_run_id, source_result_hash, policy_version, evidence_mode, typed data, unavailable_reason, and a separate projection_hash. Source hash is never renamed to projection hash. Quantities remain exact authoritative decimal strings; no float conversion or display quantization. Projection hashes exclude wall clock, process ID and file paths.

Overview projects saved H7/H15 summaries (prefix D1..DH). Short windows retain null totals and NOT_COMPUTABLE_FULL_WINDOW; no fabricated peak. Peak scope is explicitly SAVED_DAILY_CURVE_D1_THROUGH_AVAILABLE_D15, with the frozen earliest-date tie rule, not the longer remaining-business-season summary. Daily high-load ranking is descriptive quantity-descending/date-ascending, no thresholds. Curve preserves canonical saved dates, lead days, order, quantities and run identity. Incomplete hierarchy retains INCOMPLETE_CHILD_COVERAGE, missing child counts and null aggregate quantities; missing is not zero. Existing Operational Peak DB constraints do not admit zero-row completed runs; S1 does not relax that constraint. EMPTY remains a fail-safe projection state, not a claim that empty runs can be created. No new contribution percentage formula or cross-run curve composition is introduced.

Uncertainty/attribution endpoints first verify the selected saved run like other capabilities. With no compatible row authority they return NOT_AVAILABLE with explicit M1-only compatibility reason, not READY or fake empty READY payloads. Region/Company bounds are never summed from Base bounds. Attribution never publishes coefficients, means/scales, intercept or feature snapshots from private artifacts. There is deliberately no synthetic runtime adapter that would make absent authorities appear deployed; tests exercise these unavailable paths, not invented READY results.

Quality is a separate aggregate evidence query, not a run-level score. Default HISTORICAL_VALIDATION reads only explicitly allowlisted, byte-hash-pinned public JSON. It exposes M1 EXPOSED_OOT model/split/season/scope and S2/S4 policy provenance. H1/H3 interval coverage is NOT_AVAILABLE because this adapter uses S2's original H7/H15 summary, despite other later historical interval summaries. No metrics are recomputed. Current mode returns NO_CURRENT_ACTUAL with “当前产季暂无可用于正式评分的实际采收数据。” without actual/label/DB access. Point is not proven P50; planning bounds are not quantiles; historical coverage remains UNDER_NOMINAL and is not future coverage assurance. The existing backend container copies backend only, not docs; if these public files are absent, quality is NOT_AVAILABLE/PUBLIC_HISTORICAL_EVIDENCE_NOT_PACKAGED. Packaging/deployment is not changed or approved in S1.

## Authorization and failure semantics

Uses existing server-owned TrialActorDep and existing actor scope/permission contract, not a new login or permission system. Five forecast capabilities require may_read_forecast; quality requires may_read_quality. No permissions are inferred from each other.

| HTTP | Application status/code | Meaning |
| --- | --- | --- |
| 200 | READY / PARTIAL / EMPTY / NOT_AVAILABLE / NO_CURRENT_ACTUAL | Explicit business availability, not persistence/auth failure |
| 401 | UNAUTHENTICATED | A trusted upstream dependency rejects unauthenticated access; S1 adds no authentication protocol |
| 403 | FORBIDDEN | Existing actor scope/permission denial |
| 404 | SAVED_RUN_NOT_FOUND | Explicit run missing, after authorization |
| 409 | AUTHORITY_MISMATCH | Selected identity/source hash does not match, or canonical persisted/evidence integrity fails |
| 422 | INVALID_REQUEST | Invalid/unknown/oversized query fields |
| 503 | AUTHORIZATION_UNAVAILABLE / PERSISTENCE_UNAVAILABLE / READ_UNAVAILABLE | Existing server actor configuration unavailable, persistence failure, controlled unexpected internal exception |

Existing trial helpers hide forbidden resources as 404; this new namespace uses the same lower-level require_actor_scope authority and explicit 403 denial, without changing old routes. Existing auth loader is server-config based: absent config is 503, not a fabricated user-login 401. Upstream 401 is preserved if supplied by trusted auth infrastructure. No submitted client identity/header creates privileges. API errors are sanitized fixed codes/reasons; no exception messages, DB URLs, private paths, tokens or stack traces are returned.
