## Reproduction and root cause

Start saved-run verification, close before completion, reopen without editing. The original selector retained busy=true because cancellation invalidated its finally cleanup. Before correction, component regressions failed for close button, Escape and native close; real Chromium reproduced disabled retry at 1440×900 and 390×844.

## Minimal correction

Only AuthorizedSavedRunSelector.tsx changes production behavior. One cancellation function aborts, clears the active reference, invalidates generation and resets busy. Unmount cleanup invalidates without updating UI state. Closing, Escape, native close, form edits and resubmission share cancellation. Success/error processing additionally checks dialog.open: native close removes this synchronously before React receives the queued close event. Completion may clear busy only for its own still-current controller. Closed-state effect cleanup no longer steals focus from the next opener.

No layout, copy, context implementation, API, authentication, mathematical engine or dependency changes.
