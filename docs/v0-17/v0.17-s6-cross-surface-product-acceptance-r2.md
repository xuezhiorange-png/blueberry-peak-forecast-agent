## Actual test architecture

`s6_seed.py` seeds literal, explicitly synthetic saved curves into a new temporary
SQLite database. It uses the real canonical repositories and immutable saved
hierarchy snapshots; no model generator, actual reader or calibration runs.
Seeding is the only write phase. A SQL guard rejects DML/DDL after seeding;
all acceptance teardowns assert **post-seed business DML = 0**.

The unchanged S1/S2 HTTP routers and Python services read that database. The
unchanged S3 independent ASGI application uses server-owned synthetic credentials
and exact run/quality grants. Real MCP SDK `ClientSession` initializes, discovers
exactly eight tools and calls them. Text JSON equals `structuredContent`.
The browser forwards only its ordinary HTTP API traffic to this same authority.
The test driver invokes a server-side SDK audit endpoint; Dashboard never receives
MCP credentials or calls that test endpoint. Test applications are not mounted
in production, and synthetic fixtures are not imported by the production bundle.

HTTP/MCP comparisons assert complete structured business JSON equality, including
all original Decimal strings, identities, reasons, source/projection/adapter/engine
hashes, scenario rows and comparisons. Captured payloads and their derived matrix
are committed for review. Dashboard tests assert corresponding raw KPI title values,
daily strings, engine hashes and server ranks; display trimming of trailing decimal
zeroes is not treated as numeric drift. Backend parameter combinations are broader
than browser combinations; the matrix explicitly distinguishes these scopes.

## Permissions and failure semantics

MCP checks missing/wrong/duplicate credentials, missing configuration, HTTP rather
than required HTTPS, Host/Origin rejection, body limits, exact BASE/REGION/COMPANY
grants, source-hash drift, independent Quality grants and concurrent principals.
Denied run/simulation requests execute no repository session or business engine;
denied quality requests read no public quality files. Existing complete S3 safety
regression additionally exercises timeout, cancellation, disconnect, argument and
response limits, failure recovery, damaged canonical rows and missing/tampered
quality evidence. These are rerun tests, not inherited PASS_TESTED_SUBSET claims.

HTTP 401/403/404/409/413/422/503 are tested with real routers. Trusted upstream
authentication/actor failures are injected as dependencies, not fabricated
per-resource ACLs. FastAPI can construct a lazy AsyncSession dependency before
actor resolution; instrumentation proves **zero SQL before authorization**.
This does not claim zero session objects or final-user resource-level isolation.
Safe error text does not disclose SQL, secrets, paths or internal exceptions.
Browser 409 removes conflicted values; 503 retries recover the same valid identity.
