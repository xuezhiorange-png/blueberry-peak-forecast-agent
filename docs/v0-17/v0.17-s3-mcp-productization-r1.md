## Pre-implementation transport and authorization contract

Exactly eight tools directly delegate to the six S1 methods and S2 simulate/compare.
No Business Loss ninth tool. Business payloads are unchanged Pydantic JSON dumps;
success output schema is the original response model, unioned with a fixed error
model. Text JSON and structuredContent are equal. Decimal strings and all original
source/projection/adapter/engine/scenario/comparison hashes remain unchanged.

`create_forecast_intelligence_app` is an independent, unmounted ASGI factory.
Only `/mcp/forecast-intelligence` exists. POST uses the installed MCP SDK with
stateless=true/json_response=true, no event store, stdio or retained session.
Each authenticated request owns its server closure and immutable account; no
client-provided actor or shared mutable request identity is used.

Server-owned configuration supplies accounts, mandatory nonblank separate secrets,
existing may_read_forecast/may_read_quality permissions, exact run grants and
explicit quality mode/model grants. Environment configuration is
FORECAST_INTELLIGENCE_MCP_CONFIG; malformed/missing configuration returns fixed
AUTHORIZATION_UNAVAILABLE, never anonymous access. No production config is
committed. Duplicate credentials/grants, wildcards and inconsistent principals
are rejected. Secret comparison is constant-time; duplicate authentication headers
are rejected. The new header is X-Forecast-Intelligence-Key, not the legacy key.

Order: authentication → existing capability permission → exact server grant →
canonical S1 read → recheck canonical source hash → S1/S2 result. A grant binds
principal, every S1 forecast identity field and source_result_hash; read queries
without a hash are pinned to the grant, not selected as latest. REGION/COMPANY
require their own grant. Historical/current quality modes need independent explicit
quality grants and may_read_quality. Quality does not open a DB session.
Unauthorized calls open no session, read no evidence and execute no simulation.

HTTPS is mandatory by default (ASGI scope scheme; forwarded headers are not
trusted by this app). Host must exactly match a configured allowlist entry;
supplied Origin must match its own exact allowlist. Missing Origin is allowed for
non-browser clients. Duplicate Host/Origin are rejected. No wildcard hosts/origins.
Host/Origin do not authenticate. Local HTTP is enabled only by an explicit trusted
factory test configuration; deployment must configure TLS and proxy trust separately.

Limits: MCP body 262144 bytes; tool argument JSON 131072 bytes; complete response
2097152 bytes; execution deadline 30 seconds. Oversize returns a fixed diagnostic,
never truncated hashes, rows or rankings. S2 retains 20 scenarios, 15 days,
workforce 1000000, decimal-string length 64. Protocol errors remain SDK-owned.
Unsupported HTTP methods return 405. Auth/config errors are transport 401/503;
tool errors use isError=true and a fixed sanitized code/status/data=null model.
NOT_AVAILABLE and NO_CURRENT_ACTUAL are ordinary successful tool results.
