# 响应式与无障碍合同

## 断点和验证目标

≥1100px：200px 左栏，主内容最大1440px，四 KPI 一排，24px 栅格间距。700–1099px：顶部单层五项导航，四 KPI 一排，分析分栏按内容空间。≤699px：单列主内容、16px间距、KPI 2×2、表格简化成日期/数值行+详情、单情景编辑。≤479px：紧凑标题，导航短标签，不缩小桌面三列表格。

实际目标：1440×900、1280×800、1024×768、834×1112、390×844、360×800。纵向滚动允许；页面横向溢出不允许。图表全宽；表格数值不省略关键位；hash 可换行。手机导航在文档流中，不遮挡内容。横屏以同断点重新布局。视觉报告记录真实 Chromium 截图，不等于 iOS Safari 通过。

## 字体和对比

系统无衬线，正文15px、辅助13px、轴13px、标题28px、KPI32px（手机28px）；font-variant-numeric: tabular-nums。正文深色/白底，次级文案≥4.5:1为目标；状态色不单独表达含义。焦点3px蓝边+3px offset；交互目标≥44×44。使用浏览器系统字体，不依赖远端字体。200%文本放大检查换行/操作可达，不把缩小字体作为溢出修复。

## 键盘/触摸

skip link → 单层导航 → context → 页内操作；active aria-current。日期使用真实按钮，左右键切相邻日期；表格日期触发同一详情。原生 details 可键盘展开；dialog Escape、焦点返回；表单 label/错误描述显式关联。radio/select 不依赖 hover。手机长表切精简行，点击展开每日详情，不能只能看 tooltip。软键盘下字段 scrollIntoView、动作不使用覆盖式固定栏；真实设备键盘需 S5 再验，本轮桌面窄视口不能宣称 iOS 实机。

## 图表

canvas/SVG 只有图形坐标，没有业务计算。可访问名称、简短趋势说明、同源精确数据表、日期按钮；不要求屏幕阅读器解析像素。缺失断线，颜色+实线/虚线+图例区分。Tooltip 展示原始 Decimal 字符串与单位；display formatting 不回写权威输入。reduced-motion 禁止非必要动画，加载 skeleton 静态，避免闪烁。触摸/键盘能获得与鼠标同样日期详情。

## 状态与恢复

aria-busy 标注加载模块；状态更新 polite live region，错误提示 focus heading 或字段，禁止重复全页警报。missing 用“— / 暂不可用”，不是零。高量只“关注”，错误红色仅表单/服务错误，非生产告警。八状态与 Authority mismatch 有文字、原因和恢复入口。视觉 QA 不是 WCAG 全面认证；S5 必须补屏幕阅读器/真实移动浏览器/网络竞态自动化测试。
