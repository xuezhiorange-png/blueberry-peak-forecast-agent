## 产品目标与用户

PRIMARY_GOAL = PRODUCTIZE_EXISTING_V0_16_FORECAST_INTELLIGENCE_AND_DECISION_SUPPORT。

将冻结的 Hierarchical Forecast、Uncertainty、Forecast Attribution、ForecastOps、Business Loss、What-if Simulator 暴露为统一服务、HTTP API、MCP、Dashboard。V0.17 是产品化版本，不是模型开发或 prospective validation 版本。

主要用户：管理与运营人员（7/15 日数量、高峰、区域/基地贡献、产能压力）；预测与工艺工程人员（日曲线、层级下钻、区间、模型归因、历史质量、模拟）；AI 助手消费者（豆包/MCP client，与 Dashboard 使用同一 authority）。不为管理员、模型研究员、数据库操作员、安全管理员建设专门平台。

信息流固定为 FORECAST → RISK → WHY → WHAT_IF。业务优先、非技术用户可读，高级技术信息位于 secondary details/drawer，不以 IT 系统结构组织首页。

## 五项主导航与页面合同

顶层仅为：总览 OVERVIEW、预测 FORECAST、影响因素 ATTRIBUTION、产能模拟 CAPACITY_SIMULATOR、预测质量 QUALITY。不新增模型/算法/系统/用户/数据/MCP/API管理、日志中心、告警中心、配置中心。内部 concept 不是此轮冻结的具体 URL route。

### 总览

必须回答最近预计多少、高峰什么时候、风险在哪里、哪些区域/基地贡献最大。全局 context 为 hierarchy selector + forecast origin/latest saved run；层级只允许 COMPANY、REGION、BASE，不允许 FARM、FACTORY。

第一屏固定四项 KPI：FORECAST_7D_TOTAL、FORECAST_15D_TOTAL、PEAK_DATE、PEAK_DAILY_QUANTITY；默认不超过六个一级 KPI，其余 secondary。

核心曲线语义为预测值 POINT_FORECAST、80%规划上界 UPPER_PLANNING_BOUND_80、90%规划上界 UPPER_PLANNING_BOUND_90。Tooltip 必须同时说明：Point 不是已证明 P50；规划上界不是已证明 P80/P90 quantile；历史覆盖率低于 nominal；不保证未来 coverage。禁止把 P50/P80/P90 作为正式 UI 别名。

HIGH_LOAD_DATES 展示日期、预测数量、规划上界和 relative status；文案使用“关注”“较高预测量”“规划压力”，不使用 ALARM、CRITICAL、生产异常等生产告警语义。不创建生产阈值、任意红线或 SLA；具体 relative-status 展示口径由后续合同定义，不得伪装成生产事件。

Company → Region → Base 贡献比例必须来自同一 authoritative curve 与 S1 hierarchy，由统一服务提供，Dashboard 不重算数学。缺 child 不当零，aggregate peak 从聚合日曲线重算而不是 sum child peaks。

SYSTEM_CAPABILITY_STATUS 只做简洁能力说明，不做运维大屏。Forecast/Hierarchy/Uncertainty/Attribution 的 AVAILABLE 都须有对应 run/entity authority；ForecastOps 为 HISTORICAL_ONLY，Current Actual 为 NOT_AVAILABLE，不把产品支持能力等价为所有 run 都有数据。

### 预测

包括 hierarchy selector、forecast origin、H1/H3/H7/H15 prefix context、每日曲线、7/15 日总量、高峰日期/数量。日表为 date、point forecast、upper planning bound 80、upper planning bound 90；source/run metadata 放次级详情。H7 指 D1..D7，不是单独 D7。

### 影响因素

主标题“影响因素”，primary presentation 为主要影响因素、方向、相对贡献，基于 S3 exact frozen-model attribution。支持 Harvest State、BASE10、individual terms；高级详情可展示 intercept、raw contribution、clip adjustment、serialization adjustment，但仍服从已授权 sanitized authority 与隐私边界，不公开 raw model parameters。

固定 MODEL_ATTRIBUTION_ONLY=true、ATTRIBUTION_IS_CAUSAL=false。推荐“模型中对本次预测贡献较大”；禁止“导致”“原因就是”“造成产量变化”等因果表述。S3 只绑定已冻结 M1 模型，不能给未绑定模型或任意 saved run 编造解释；relative contribution 不得丢弃负号或将 clip/serialization adjustment 偷分配给业务特征。

### 产能模拟

只复用 S6：hierarchy entity；planning level 为 POINT / UPPER_PLANNING_BOUND_80 / UPPER_PLANNING_BOUND_90；DIRECT 提供 daily_handling_capacity_kg，WORKFORCE_DERIVED 提供 workforce_count 与 productivity_kg_per_person_day，其乘积为 capacity，禁止隐藏 productivity。可显式提供 buffer_handling_capacity_kg，它是 SAME_DAY_ADDITIVE_HANDLING_CAPACITY，不是储存库存，不跨日结转。initial backlog 固定 0。

输出 OVERLOAD_DAY_COUNT、CUMULATIVE_SHORTFALL_KG、MAX_BACKLOG_KG、ENDING_BACKLOG_KG、AGGREGATE_CAPACITY_UTILIZATION、BUSINESS_LOSS，以及 demand-vs-capacity 与 backlog 曲线。日过载是新需求与同日产能的 gross gap，不等于跨日 backlog。沿用 S6 mass balance、S5 loss mapping，不新增算法。

Utilization 精确 authority 为 numerator/denominator pair；仅其派生 Decimal50 ROUND_HALF_EVEN 表示沿用 S6 数值例外，禁止参与 ranking 或数量计算。

用户显式创建 Scenario A/B/C…；比较必须同 forecast、hierarchy、planning level、date set、cost contract。只展示“条件情景排序”，禁止“最优方案”“系统推荐方案”“最佳人员配置”。不自动搜索产能、生成 workforce、优化、LP/MILP、自动推荐或执行。

Business Loss 必须显示 cost authority。Synthetic contract 显著标记 SYNTHETIC_COST，单位 SYNTHETIC_LOSS_UNIT；不能显示人民币损失、节省或 ROI。当前 CANONICAL_COMPANY_COST_ESTABLISHED=false、REAL_ROI_VALIDATED=false；真实成本只能未来另行授权提供，禁止隐含默认成本。

### 预测质量

默认 HISTORICAL_VALIDATION，证据标记 RETROSPECTIVE_OBSERVATION。展示 H1/H3/H7/H15 的 WAPE、MAE、Bias、Cumulative WAPE、interval coverage。历史结果不得冒充 CURRENT_PRODUCTION_ACCURACY。

必须保留负面事实：S2 H7 PI80 约 53.9%、PI90 约 74.5%；H15 PI80 约 50.6%、PI90 约 71.1%。均低于 nominal 80%/90%，不能隐藏、改绿或称成功达到名义覆盖。H7 Upper80/90 约 72.1%/82.3%，H15 约 70.5%/80.9%，同样低于名义水平。精确值、candidate/computable/not-computable counts 来自 source-bound S2 coverage summary，机器 evidence 原值保留；没有重跑 calibration。

当前 CURRENT_SEASON_ACTUAL_AVAILABLE=false、REQUIRED=false，读取/导入/评分均未授权。必须显示：“当前产季暂无可用于正式评分的实际采收数据。”不得伪造、读取当前实际数据，或以历史/synthetic 数据冒充当前数据。

## 单一 Authority 架构与能力集

V0_16_FROZEN_ENGINES → FORECAST_INTELLIGENCE_SERVICE_LAYER → HTTP API / MCP / Dashboard。Dashboard 经 HTTP API 消费该 authority；三个 surface 不复制公式、不各算一套。相同 forecast run、entity、planning level、scenario inputs、authority 必须得到同一 authoritative quantity、result hash、semantic status；允许 presentation formatting 差异，不允许数值/结果差异。

API 能力集固定为 GET_FORECAST_OVERVIEW、GET_FORECAST_CURVE、GET_HIERARCHICAL_FORECAST、GET_FORECAST_UNCERTAINTY、GET_FORECAST_ATTRIBUTION、GET_FORECAST_QUALITY、SIMULATE_CAPACITY、COMPARE_CAPACITY_SCENARIOS。本轮不冻结具体 URL path。MCP 对应 get_forecast_overview、get_forecast_curve、get_hierarchical_forecast、get_forecast_uncertainty、get_forecast_attribution、get_forecast_quality、simulate_capacity、compare_capacity_scenarios；S3 可微调 transport naming，不扩大能力集。Business Loss exposure 属于 S2 明确范围，不借此扩建通用管理 API。

V0.16 模型、hierarchy、uncertainty、attribution、ForecastOps、business loss、what-if 数学全部冻结。产品层仅 expose、compose、format、query、visualize，不改变引擎结果，不训练/refit/tune、不变特征或 Harvest State。

## Authority 缺失与产品状态

核心页面都须支持 LOADING、READY、EMPTY、PARTIAL、NOT_AVAILABLE、ERROR、AUTHORITY_MISMATCH、NO_CURRENT_ACTUAL。不得 blank screen、NaN、missing 用 0 代替或 catch-all“系统错误”。

V0.16 未建立 Region/Company 区间校准；不能 sum Base bounds 宣称 aggregate coverage、fallback 到 point/零或重新 calibration。曲线区域可保留语义槽位，但无合法绑定数据时显式 NOT_AVAILABLE/null。完整 point hierarchy 不等于完整 uncertainty/attribution authority。source/policy mismatch 返回 AUTHORITY_MISMATCH，不显示貌似合法的结果。

Historical authority 保持 STRICT_PIT=false、HISTORICAL_ACTUAL_AVAILABLE_AT_PROVEN=false、RETROSPECTIVE_AUTHORITY_USED=true。产品化不修复历史 available_at 证明，也不产生 prospective validation。

## Frontend、响应式与可访问性方向

复用 React / Vite / TypeScript、现有 ForecastPage / QualityPage；允许 S5 重构、拆分、迁移 route，不另起 Next.js/Vue/Angular。Desktop primary，mobile responsive；手机可查看关键结果、完成基本 scenario input，高级表格与详情可以适配而非原样挤入。

现代专业 B2B analytics、业务优先、信息密度高但不拥挤、非 AI chat UI。优先层级、可读性、留白、对齐、chart typography；避免大面积渐变、过度 glow、随机玻璃拟态、紫蓝 AI 风、大量 emoji、花哨 3D。这里只冻结方向，不设计完整 Dashboard/Design System；具体视觉合同在 S4。

必须有 keyboard navigation、semantic HTML、visible focus、contrast、chart text alternative/data table；loading/empty/error/partial 状态均属验收，不只测 happy path。
