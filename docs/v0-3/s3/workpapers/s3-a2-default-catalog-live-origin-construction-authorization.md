## 3. What this authorization grants

A later default catalog live-origin construction R1 may, under a separate user
「可以实施」 gate:

1. Reuse the already-landed default catalog live-origin obtain and the existing `#476`
   family only. No new SQLAlchemy API family.
2. Connect that obtain into bare default catalog construction so that
   `EvaluationInstanceCatalogArtifactProductionService` built with dataset identity
   alone may produce `ARTIFACT_PRODUCED` when the landed origin and bound TRAIN/VAL
   actuals are available.
3. Keep fail-closed behavior when origin rows, bound actuals, or session making are
   unavailable. Leave the default session provider unset after the construction call.
4. Inject or resolve ports **without rewriting** frozen catalog production bytes.
5. Keep TEST sealed. Cutoffs must not be derived from harvest dates.

A later R1 may not:

- invent weather, plans, maturity, residual, or tonnes
- add a new SQLAlchemy API family
- unseal TEST
- flip `NO_VERSIONED_INCUMBENT_FORECAST_ARTIFACT_IN_REPOSITORY`
- flip `NO_REVIEWED_GRAIN_IDENTITY_SET_IN_REPOSITORY`
- flip `NO_BINDABLE_CATALOG_IN_REPOSITORY`
- flip completeness verified or authorize completeness PASS
- treat templates as live weather or plans
- mutate frozen blobs listed in §4

This grant itself performs none of the above.
