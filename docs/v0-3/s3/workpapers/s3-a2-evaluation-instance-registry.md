This workpaper records the S3-A2 evaluation instance registry **contract freeze**
after PR #307 window-level `CompletenessVerifier`. Amendment §8.1 requires
predicate proof for each evaluation instance cell and requested window. Without a
versioned cell catalog, dataset-level completeness verification cannot close out
and `CURRENT_S3_DAILY_ROWSET_COMPLETENESS_VERIFIED` must remain `false`.

This PR defines registry grain, inclusion rules, source authority, fail-closed
state, and dataset-level VERIFIED necessary conditions. It does **not** implement
the registry, materialize cell rows, run predicates, or flip VERIFIED.
