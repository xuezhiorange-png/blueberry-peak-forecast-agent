## 2. Why this contract is the unique remaining gap

1. Bindable-name R1 (#359) encoded frozen name `s3_incumbent_forecast_replay_identity`;
   `bindable_table_names()` returns that 1-tuple; `NO_BINDABLE_V0_2=false`.
2. `IncumbentForecastReplaySource._empty_v0_2_postgres_obtain` consults
   `bindable_table_names()`, finds it non-empty, then still returns `()`.
3. That second empty return is the unique remaining code gap. It is not live postgres read.
4. Empty Alembic table still has 0 rows. Later live-read of the empty table still yields
   `obtain()=()`.
5. Default catalog first blocker remains `NO_VERSIONED_INCUMBENT_FORECAST_ARTIFACT`.
6. Parent obtain §3.1: bind only to coordinator-reviewed frozen names already in repository
   contracts. That name now exists. This contract is the live-read authority freeze for that
   name.
7. This contract does not implement the read, populate rows, flip `NO_VERSIONED`, or close S3.

Do not treat encoded bindable name as live-read implementation fact. Do not jump to
live-read R1 in this merge.
