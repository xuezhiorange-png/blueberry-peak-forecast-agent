This document freezes the V0.3-S3 **metric execution contract**. It defines how
a future authorized deterministic metric service must apply the frozen V0.2 formula
authority to a legal TRAIN/VALIDATION backtest pairing or diagnostic package and
emit honest `NOT_COMPUTABLE` statuses. It is a governance contract, not a metric
results package, coverage package, backtest run, attribution matrix, S1 formula
acceptance, or S4 authorization.

Merging this contract does **not** authorize metric execution, live §4.4 insertion,
TEST evaluation, production or test code, formula mutation, or model change.
`S3_METRIC_EXECUTION_AUTHORIZED` remains `false` after merge.

`S3_METRIC_EXECUTION_CONTRACT_AUTHORIZED=true` (file fence) ≠ live §4.4 authority
≠ `S3_METRIC_EXECUTION_AUTHORIZED` ≠ metrics computed ≠ runner implemented ≠ C0
`CURRENT_S3_C_BACKTEST_EXECUTION_STATUS` flipped ≠ S3-D
`CURRENT_S3_D_ATTRIBUTION_EXECUTION_STATUS` flipped ≠ completeness verified ≠
`NO_VERSIONED` flipped ≠ S3-B coverage authorized ≠ S1 acceptance ≠ formula
change ≠ 3 vs 7 resolved ≠ TEST unsealed ≠ S4 authorized. This evidence JSON is
not a metric results package, backtest package, attribution matrix, or versioned
forecast artifact. Catalog first blocker remains
