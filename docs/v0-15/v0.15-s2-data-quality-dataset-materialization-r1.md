## 数值定义及质量规则

Base10 不另造定义，直接调用 V0.14 shadow issuance 所使用的
`weather_aware_backtest._base_feature_values`，并绑定该文件的 SHA256。
对每个 D1–D15 日期计算冻结面积、季节进度和一阶/二阶周期项。
面积必须为 finite positive authority value。不 fit scaler、encoder 或 imputer。

标签是独立 application path：D1 为 origin 次日，D15 为 origin+15 日；
只接受 `VALID_OBSERVED` 和精确为零的 `REAL_ZERO`。
H7/H15 不使用 partial denominator；单日及 rolling-7 峰值都采用 earliest tie。
UNKNOWN、PARTIAL_SUBTOTAL、MISSING、CONFLICTING、INVALID 不补零、不变成完整标签。
重复 logical key、非法重量、断裂 lineage 等 fail closed。

质量报告区分 `INVALID_EXCLUDE`、`SUSPECT_REVIEW`、`VALID_EXTREME_KEEP`。
没有模型误差、没有统计阈值拟合，也没有自动删除峰值。
报告中的 `valid_extreme_keep_count` 表示保留全部通过质量规则的 origins，
不声称这些 origins 全是统计异常值。源记录分类只做原样计数，不重新分类。

Weather8 只处理 S1 已冻结的 weather-comparable origins，采用同一个 ECMWF
operational run、84 个 instantaneous steps 和 256 个 required fields。
官方镜像 index 必须与 S0 已冻结 receipt byte-hash 相同，再按字段 byte range
下载 GRIB，并用 native ecCodes 实际解码、按冻结 0.25° nearest-grid policy
提取已有 location authority 对应点。没有联网重新定位、插值或跨 run 补字段。

聚合复用 `v014_future_weather_features.aggregate_ifs`，保持温度、风和 ssrd
的原定义；仅在历史 replay adapter 中应用 S0 已冻结的降水差分规则：
block-B 差分绝对负异常必须小于 0.08 mm，阈值以下的极小正/负差分归零。
更大的负异常拒绝；不把该规则推广到 ssrd 或即时量，也不修改 V0.14 provider。
publication policy 仍是 Tier B `issue+8h`，不是实际历史 publication timestamp。

Weather TRAIN=0 原样保留。即使 VALIDATION/OOT 的数值全部物化成功，
`WEATHER_BENCHMARK_TRAINING_READY=false`；不重切 split、不用 reanalysis 替代。

## 私有数据与隔离证据

选择 Owner 允许的受控私有 artifact 路线，不创建或修改历史数据库表。
使用经 S0 hash 验证的只读、ROLLBACK 历史 snapshot 和 logical projection；
原始 raw/authority evidence、生产数据库、V0.14 runtime/registry/scheduler
及冷库服务均不修改。

私有目录分为 `feature_zone`、`label_zone`、`audit`；目录 0700，文件 0600。
独立 materializer 可读取授权历史 labels，feature builder 不接受 label 输入。
公开 feature-reader 只接受解析后位于 feature_zone 的文件，拒绝 label 路径和
跨区 symlink，并只返回数值 features/row keys/feature hashes，不把 label hash
等 target lineage 元数据暴露给 predictor input。
reader 还必须收到从冻结 manifest 取得的 expected file SHA256，文件 drift 即拒绝。

数据库证明使用 `BEGIN READ ONLY`、`SHOW transaction_read_only=on` 和 `ROLLBACK`，
实际验证现有 predictor role 的 label_vault SELECT 被拒绝；只查权限和 schema
metadata，没有查 harvest quantities、修改认证或提升角色。
这不宣称改变了现有 localhost authentication，也不宣称建立了 OS-user 级隔离。
artifact 的授权 reader/application boundary 与数据库 role denial 分别记录。

原始全球 GRIB 在 bounded memory 中解码后释放；保留 raw SHA256/size/metadata
receipt 和私有 point-value cache，供离线数值重放。公开 Git 只保存实现、
synthetic tests、聚合计数、hashes 和 sanitized manifests。
不保存采收量、标签向量、坐标、天气值、credentials、原始 GRIB 或私有路径。

## 操作与复现

1. 用 `scripts/verify_v0_15_s2_isolation.py` 生成只读权限/schema receipt。
2. 用 `scripts/acquire_v0_15_s2_weather.py` 显式 `--network` 建立历史私有
   numeric cache；输入是 frozen catalogs/location/S1 artifacts，不接受标签。
3. 用 `scripts/materialize_v0_15_s2_dataset.py` 传入 repository、snapshot、
   projection、weather-cache、private-output、public-output、isolation-receipt。
   输入路径仅通过私有 operator command 提供，不写入公开配置。
4. 固定完整 cache 后，在两个 fresh output directories 各执行一次 materializer；
   比较全部私有/公开输出的 bytes 和 SHA256。相同文件只能幂等复用，不可覆盖。
5. 查看 source-pinned manifest、split-quality、显式 failed-row decisions、
   privacy scan 和 replay receipts。Base 成功+失败必须为 20,020；Weather 为 12,925。

同一输入两次 pure-function byte parity 和两次独立进程 file parity 是不同证据，
分别报告。synthetic CI 不依赖私有数据、数据库 credentials 或 archive network。
exact-head CI 与本地聚焦/回归检查也分别报告，不用本地结果冒充 CI。

后续 Base10 可以作为公平研究的数据输入，但仍需独立模型任务授权。
Weather benchmark 保持关闭，S3/Ready/Merge/production approval 均未授权。

## 本轮真实物化结果

Base10 与独立历史标签均为 20,020 origins，失败为 0；分别对应
TRAIN 4,125、VALIDATION 6,028、EXPOSED_OOT 9,867。每个 origin 的
15 日标签完整，形成 300,300 个重叠 target-day instances；不是这么多独立采收记录。

Weather8 已为 12,925 origins 生成完整八值向量，失败为 0：TRAIN 0、
VALIDATION 3,058、EXPOSED_OOT 9,867。仅处理 S1 已准入的 392 个 unique runs，
真实 ecCodes 解码 100,352 个 GRIB fields；没有重启历史 coverage sweep。
decoded GRIB 字节量为 79,359,982,775，包含既有 raw cache 重用，
不能将该数字声称为本轮新增网络下载量。全球 raw messages 解码后释放，
保留私有 point cache 和逐字段 SHA256/size/native metadata receipts。

33,033 条 source logical records 的逐季描述性审计未发现负数、非有限值、
REAL_ZERO 非零、complete-state 缺数量、断裂 lineage 或越出 business boundary。
UNKNOWN 与 PARTIAL_SUBTOTAL 原样保留，未重新准入、不补零；没有拟合统计阈值。
所有准入的有效 origins 均保留，没有按峰值、异常值或模型误差删除记录。

完整文件回放、权限与 public privacy 验证见 supplemental operator receipts；
其独立 manifest 绑定原始 dataset manifest，不覆盖 materializer 产生的证据。
这些结果不是模型性能、严格历史 PIT 或生产可用性结论。
