## 四阶段标签 custody

1. `phase-a`：先持久化候选/指标合同，再仅打开 TRAIN 标签。训练固定 7 个候选，
   生成全部 Validation 预测并封存文件 hashes；不打开 Validation/OOT 标签。
2. `phase-b`：验证完整 seal、候选集合、文件 hashes 和 common rowset 后，才打开 Validation
   标签。按 H15 daily WAPE、H7 daily WAPE、daily MAE、complexity、lexical ID 选择 tree 配置。
   Complexity 在看标签前冻结为 CatBoost `(depth, iterations)`、LightGBM
   `(num_leaves, max_depth, n_estimators)` 的 lexicographic order。
3. `final-fit-seal`：再次核验 selection，允许 TRAIN+VALIDATION 标签；按 152,295 target rows
   拟合最终三模型，生成 OOT 预测并封存。OOT 标签仍未打开。
4. `score-oot`：先验证 OOT seal/文件/common rowset，再打开 OOT 标签，评分一次并停止。
   禁止改变 selection 或再拟合。失败留下 invalidation，真实结果不能覆盖或未经授权重跑。

预检只读取 manifest 中的 expected label hashes，不读取/哈希实际待封存分区标签文件。
实际 label bytes 的 hash 校验发生在对应阶段获准解锁以后、解析标签以前；drift 则 fail closed。
私有 seal 保存内部生成时间，Git 只锚定 hashes，不提供外部 trusted timestamp。
这属于可审计 application-path 隔离，不宣称 OS-user 或硬件 label vault 隔离。

## 指标与公平性

全部评分使用 Decimal（precision=50），不做 display-level 中间 rounding。WAPE 为 ratio，
不是百分比；daily WAPE 分母包括所有重复 origin-target 实例。H7/H15 cumulative WAPE
以每 origin 累计总量的绝对误差求和，再除实际累计总量。MAE/Bias 以 target-row 平均，
同时报告 total signed bias。D1–D15 逐 lead、单日峰值和 9 个 rolling-7 window 均报告；
峰值并列采用 earliest date。

Curve shape error 继承项目 scale-normalized curve 语义：每 origin 将预测按实际总量缩放，
累积绝对差后除实际总量。任何 origin 实际或预测总量不正则整项为 undefined，
单列 undefined count，不偷偷删行形成不同 denominator。

Validation 与 OOT 单独报告 Base breadth；Base 明细只在私有区。LEAVE_TOP1/2 按 tree
相对 Ridge 的 H15 daily absolute-error reduction 排序，移除整个 Base 再算 H7/H15 WAPE；
只诊断集中度，不用于调参。Research leader 按 OOT H15/H7/cumulative/peak-date/simpler-family
排序；Validation 与 OOT 方向不一致时保守报告 NO_CLEAR_LEADER。Tree supported direction
必须两阶段 H7/H15 四项全部优于 Ridge。研究领先不等于 prospective 验证或生产批准。

## 实测结论

两个独立四阶段实验的预测与评分 bytes/hashes 完全相同，选择结果均为 CB1 / LGB1。
Validation H15 daily WAPE：Ridge 75.5212%、CatBoost 69.1307%、LightGBM 70.2513%。
Exposed-OOT H15 daily WAPE：Ridge 62.9438%、CatBoost 64.1767%、LightGBM 65.7429%。
这里只为可读性显示百分比；机器可读 evidence 保留 Decimal ratio 全精度。

两树模型都是 Validation 改善、OOT 退化，因此各自方向为 MIXED，
BASE10_RESEARCH_LEADER=NO_CLEAR_LEADER。不能据本实验声称树模型稳定优于 Ridge。
BASE10 是可用于公平研究的固定赛道，不意味着绝对误差已经达到生产可用水平。
