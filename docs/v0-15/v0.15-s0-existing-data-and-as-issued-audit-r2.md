## 历史真实预报 proof

对 2025-01-15 00Z 实际请求 ECMWF Archive Catalogue，并发送最小 MARS retrieval POST：class=od、stream=oper、type=fc、expver=1、sfc、2t、step3。目录返回 200，参数轴含 2t/10u/10v/tp/ssrd，时效轴含全部 84 个所需 step。但各轴存在不证明完整 256-field joint availability。

MARS 下载 POST 返回 403 `Missing access token`，未进入 request-validation/retrieval queue，未取得 GRIB；原始 request/response receipt 在独立 research scratch 保留。旧 Open Data 历史 index 的 404 只证明该 rolling URL 不存在，不代表 MARS 无 archive。

因此八个 Weather8 feature 均为 ARCHIVE_EXISTS_ACCESS_BLOCKED，0–168 和 168–360 均未完成重建。已验证完整/部分 as-issued Base×Season 数均为 0：这是 **verified coverage**，不是 archive 实际不存在。strict PIT ready 数为 0，还缺历史发布可用时间、area/identity known-at。

矩阵仅将杨柳 2024–2025 的代表日期 proof 记为 access-blocked；其余格为 NOT_AUDITED。不把一个目录请求推论成所有历史日期/Base 都已检索。393 个来源字段实体是审计 quarantine，不是认定其都是农场；后续应先审查字段/表头错位与 applicability，再判断是否需要 identity authority。

ECMWF 官方依据及本轮 HTTP receipts 见 [archive report](evidence/historical-as-issued-archive-report-r2.json)。[archive access](https://www.ecmwf.int/en/forecasts/access-forecasts/access-archive-datasets) 与 [Web API](https://www.ecmwf.int/en/computing/software/ecmwf-web-api) 说明归档及访问机制；[Open Data](https://www.ecmwf.int/en/forecasts/datasets/open-data) 的 rolling retention 不可当长历史 archive。TIGGE 的 net solar ssr 不能替代 downward ssrd，6h sampling 也不能自动满足现有 Weather8。
