## PIT tier 正式冻结

- Tier A STRICT：具体 payload lineage 和直接不可变系统时序证据，available_at 不晚于 origin。
- Tier B ASSUMED：真实数据及预先冻结、与结果无关的保守 availability assumption；不是 strict PIT。
- Tier C RETROSPECTIVE：仅能证明最终历史存在，用于 exploratory/proxy，不进入 strict blind PIT。

event/effective/source/created/ingested/updated/available/retrieved 时间分别保留。
字段名或文件 mtime 不证明不可变历史 ingestion；事后追认不回填为当时已知。
当前 117 条已确认面积均为 Tier C，A=0、B=0。未实例化任何假设规则。
未绑定来源标签保留 UNCLASSIFIED_NO_BOUND_AUTHORITY，不因矩阵存在就获得 Tier C authority。
identity unresolved 仍为 44 条 mapping rows，不是 44 个 Base；strict authority verified=0。
不 fuzzy merge，不创建或修改 area/identity authority。
