## KNOWN_LIMITATIONS

Weather8 已数值物化 12,925 origins（Validation 3,058 / OOT 9,867），但 TRAIN=0；公平三段 Weather benchmark 未执行。结论是因缺少 comparable TRAIN weather cohort，Weather incremental value 未在 V0.15 建立，不等于天气无价值或被否定。未使用 reanalysis 替代，未为天气改 temporal split。

历史 area / identity 缺少 cutoff 前 available_at 严格凭证。Harvest State 为 RETROSPECTIVE_DATE_BOUND：17:00 Asia/Shanghai origin 仅使用 business_date < origin local date 的采收，origin 当天完整采收不进入特征。未来日泄漏被阻断，不代表每条历史业务记录在 exact 17:00 已进入系统。

Curve Shape 按冻结合同：存在 zero-total origin 时整体 undefined/null；没有删除 zero-total rows 重算，未用于建立 S5 SUPPORT。
