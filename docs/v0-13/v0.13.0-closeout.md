不拼接 origins，不声称整季峰值。沿用最早日期 tie 和完整连续七日累计峰值。

## Oracle：未来实况信息上界仍是 mixed

一个 28-feature Oracle 使用 target-date anchored ERA5-Land **future realized** weather，
不是 ECMWF as-issued forecast。仅描述性比较 O1−M1 与 O1−M0，不进入主 decision fields，
SUPPORT_CLASSIFICATION=NOT_APPLICABLE_RESEARCH_UPPER_BOUND_ONLY。

相对 M1，单日日期 Combined 改善 0.775479313824419778002018164 天，两个 fold 都改善。
rolling7 A 退化 +0.376797698945349952061361458 天，B 改善
-0.199246833276275248202670319 天，Combined -0.047679112008072653884964682 天。
方向不一致，Combined shape 不可计算，故 ORACLE_UPPER_BOUND_EVIDENCE=MIXED。
这提示未来天气可能含有部分单日峰时信息，但未证明稳定的两折 rolling7 timing solution；
不能据此声称未来天气无用，也不能声称 Oracle 解决了峰时问题。

S4 先封存两个 Oracle fold，才首次访问 S3 scored rows，连 pre-seal SHA256/stat 都禁止。
R1 未验收诊断曾可见，R2_RESULT_BLIND=false；未用于调参。R3 仅修正实现与 S0 规则
不一致的分类条件，不改 raw metrics、模型、features、cohort 或 Oracle。
S5 只引用已提交的验收结果，不重跑、更不重新作出 Oracle 科学分类。

## 推荐方向不是授权

数量方向：PROSPECTIVE_AS_ISSUED_WEATHER_VALIDATION。
ERA5_FORECAST_TIME_KNOWN_AT_STATUS=NOT_ESTABLISHED，production-like weather validation
仍 false。已发生天气的历史信号不等于当时真正可获取的天气预报信号；需独立授权的
issued_at / known_at≤origin、预报 snapshot seal、未来 actual 积累和 locked scoring。

峰时方向：DIRECT_PHENOLOGY_AND_IN_SEASON_STATE_RESEARCH。
优先候选是直接物候锚点、品种/botanical 身份、树龄/产能结构、花/坐果观测、
当季采收进程及成熟/可采库存状态。这些是更有信息价值的研究候选，**尚未被证明更好**。
当前 past-weather/GDD timing 不支持，Oracle mixed，不应继续在同批特征上结果后搜索。

当前 7°C rolling GDD 降低研发优先级，不永久禁止 thermal time。
若重启，必须新版本以及新 biological authority 或新预声明假设。
