## Fixed representation

Policy: `V0_13_S2_GDD_7C_ROLLING_V1`.
Definition: `V0_13_GDD_7C_SIMPLE_MEAN_R1`.

Daily GDD is `max(0, (Tmax + Tmin) / 2 - 7.0)`. Tmin is not preclipped.
There is no upper cap. W7/W14/W30 sum origin-7/14/30 through origin-1,
inclusive, and never use target-date or origin-day temperature. Decimal
precision is at least 50; each window is rounded once to 12 decimal places
with ROUND_HALF_EVEN. No season-to-date, alternative threshold, extra window,
feature search or Oracle execution is authorized.

Missing/invalid days fail closed with explicit reasons. Duplicate days,
missing extrema, nonfinite temperatures, Tmax below Tmin, incorrect day/unit/
timezone metadata and missing required calendar dates cannot silently become zero.
Nonnegative nested windows satisfy W30 >= W14 >= W7 >= 0.
