## 封存与不可变性

执行顺序为：读取 2023–24 labels → train/predict Fold A → durable seal A →
首次解析 2024–25 → train/predict Fold B → durable seal B → 两 seal 验证 →
首次 metric score A → 首次解析 2025–26 → score B。
file SHA256 的 preflight 不解析 validation labels。

seal 绑定四模型 ID、artifact hashes、prediction hashes、prediction file SHA256、
row count/hash、weather/GDD hash 和 business boundary。评分后重新核验全部
封存文件。score 开始后 guard 拒绝 fit；leave-top 只重评分，不 refit。
新 `V0_13_RIDGE_ARTIFACT_V1` 显式包含 standardization 和 zero_std_policy，
8 个新 artifact 全部 direct self-hash valid；不复制 V0.7 serializer 缺口。

M0/M1 的旧 compatibility hashes、逐字段参数、prediction hashes 和所有
Fold A/B/Combined H1/H7/H15 WAPE 精确复现 V0.7，失败即停止而不解释 GDD。

所有 source（含 frozen registry/mappings、weather、S2 artifacts）在运行前后
SHA256、size、mtime_ns 一致。最终两次独立 Python process 的 15 个文件
逐 byte 相同；report hash：
`8bb56ca765518c8f60ffd62ffdaf3154e89fda782557e5907ac156360e444dd5`。
开发期两次 adapter 接口错误发生在任何 fit 之前，保留失败目录；没有成绩驱动调参。

## 验证与使用

操作入口：`python -m scripts.run_v0_13_s3_four_model_oot --help`。
必须提供三个 frozen workbook、weather、registry、两个 identity mapping、S2 GDD
目录和新的不存在的 output。输入路径只由 operator 提供，不提交 Git。
失败目录不被宣称为成功；成功 evidence 只在所有 gate、immutability checks 完成后写出。
第二次 replay 必须新进程、新目录，不复用模型或 score cache。

Private output 每 fold 保存四 artifacts、predictions-before-scoring.jsonl、seal、
scored-rows.jsonl（包括 actual status/source hash），供单独授权的 S4 使用。
Git 不包含 workbook、weather/GDD rows、prediction/actual rows、private artifact、
本地路径。public evidence 去掉重复 pair metric 与完整贡献者列表，只留 top-two IDs；
其中 report_hash 绑定原始 controlled report，而不是 sanitized projection 自身。
FINAL_HEAD_SHA 和 exact-head CI 由 PR/最终回执独立绑定，避免自引用和 CI 后改 Head。

当前 focused synthetic tests=61；failure injection=52/52。CI 不需要私有输入。
除 formula/cohort/algorithm mutations，测试 durable seal tamper、提前读取/评分、
post-score fit、unknown-to-zero、zero denominator、daily/cumulative 区分、pooled
aggregation、combined 同 Base 跨 fold 全部移除、以及 incomplete gate evidence。
