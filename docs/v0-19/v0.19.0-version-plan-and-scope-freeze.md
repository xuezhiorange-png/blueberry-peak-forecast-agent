## 2. 研究目标与非目标

1. 诊断并改善每日采收量曲线的时间分辨率。
2. 研究提高单日采收峰日期预测准确性的方法。
3. 研究提高完整连续七日累计采收高峰预测准确性的方法。
4. 使用相同历史样本、物理口径和指标进行独立对照。
5. 明确开花、促早、剪枝等农艺信息未来的算法价值假设及接入优先级。

研究成功不以 Agent、MCP、Dashboard 或治理文件数量衡量。
不开发业务页面、加工厂分配、生产接口或新的权限系统；不改 V0.18 产品目标。
不改变现有预测模型、业务数学、ForecastIdentity、结果 Hash 或冻结证据。
PRODUCTION_READY=false；MODEL_PROMOTION_AUTHORIZED=false。
研究候选不替换线上/冻结模型，不自动注册为业务权威。

## 4. 统一对象及指标边界（S1 完成协议，不在 S0 实现）

必须分别登记 AREA_FORECAST_PRODUCT、OPERATIONAL_PEAK、
V0_15_BASE10_RIDGE、V0_15_HARVEST_STATE_RIDGE、CORE_FORECAST；
记录模型版本、fit state、来源、实体/面积口径、产季、origin、时区、发行时间、
输入可用时间、label authority、完整性、单位和预测窗口。未知字段不得猜测。

指标最小集合：SEASON_TOTAL_WAPE、DAILY_WAPE、DAILY_MAE、
SINGLE_DAY_PEAK_DATE_MAE、SINGLE_DAY_PEAK_QUANTITY_MAE、
ROLLING_7DAY_PEAK_START_MAE、ROLLING_7DAY_PEAK_QUANTITY_MAE、
BASE_BREADTH、SAMPLE_COVERAGE、NOT_COMPUTABLE_COUNT。

- 总量与逐日误差、峰日期与峰量分别评价，不用一个指标代表全部改善。
- 单日峰取同一权威曲线最大日量；完整 rolling7 取连续七个日历日之和最大窗口，
  并列沿用最早日期。缺日期不补零；不完整窗口不可计算，保留原因和计数。
- H7 prefix 是 D1..D7 累计；H15 局部峰仅属于该 origin 的完整 D1..D15。
  局部峰与完整产季峰分开报告，不拼接 origins 冒充整季预测。
- 完整产季总量与逐日量不能混同；七日量不是第七日单值。
- 真实采收与到厂量代理不混合；无合法基地→加工厂归属及处理能力来源则不可推断分配。
- WAPE 的分子分母、零分母、MAE 权重、重复 origin-target、
  负向/退化、不可计算规则、breadth 与共同样本键在 S1 预注册后才允许实验。
- 样本、季节、物理口径、训练及评价时间、预测对象必须可比；
  不能跨模型家族/不同样本直接排名。S1 不重新评分旧数据。

### S1 — 基线与峰误差协议

业务目标：统一对象、基线和可比较评价，不再混用历史模型身份。
输入仅为已授权公开冻结合同/聚合证据；任何私有行、标签或新评分另需授权。
交付统一算法对照合同、峰值指标合同、历史误差证据矩阵、候选实验预注册协议。
验收要求五种模型家族及第 4 节全部口径、分母、窗口、来源完整性及暴露状态明确；
锁定正式基线和选参规则后才进入 S2/S3。模块边界为独立研究协议/证据/合同测试，
具体路径在单独实施授权确定。非目标：重新评分、训练、业务服务改动。

### S2 — 最多一个日曲线候选

目标针对七日分箱的时间分辨率限制，研究受约束插值或每日分布重建；
本 S0 不选择具体算法或参数。方法与参数选择规则必须在查看实验结果前冻结。
保留 Operational Peak 基线，候选只在独立研究路径，不改冻结业务模型。
输入为已批准的结构/合成曲线；无新增数据访问授权。
必须逐日非负、数值稳定、质量守恒、日期连续、输入相同结果确定、无隐藏参数；
不得使用目标日未来实际采收，不得人为固定峰提前/延后天数。
质量守恒的作用域、边界处理和数值精度在 S1/候选数学定义中先冻结，不观察结果后改。
交付可运行研究候选、数学定义、合成测试、确定性结果、与基线结构差异说明。
验收全部结构约束、至多一个新候选及隔离路径；不宣称精度改善或生产晋级。
预计仅独立研究算法、合成测试、研究文档；未来文件边界需 Owner 批准。

### S3 — 受控独立对照

在单独数据和实验授权后，与 S1 正式选定的对应基线比较；
同来源、对象、训练/评价范围、样本和物理口径，预处理/参数仅从允许训练验证范围确定。
预测和标签独立保管；先封存预测，再由获授权评价路径开标签；保留全部失败/退化/不可计算。
报告第 4 节十项指标，分别给完整产季与 H15 局部窗口、跨基地稳健性和共同样本覆盖。
2025–2026 只能为 exposed historical benchmark，2026–2027 当前季实际数据禁止未授权访问。
数据/时点证明不足必须 RESULT=BLOCKED，不能生成虚假分数或换样本掩盖。
交付基线候选对照、误差分析、跨基地稳健性、增益/退化结论和可复核 seals/hashes。
预计只读研究执行器/评分器和证据路径，须在数据/实验授权中明确，不触碰业务模型。
验收口径、独立性和可复核证据，而非必须正增益；业务精度阈值不得凭空设定。

### S4 — 农艺价值及研究收口

结合 S1–S3，优先评估：开花开始/盛花/结束；品种及地块面积关联；
促早操作及时间；剪枝类型/时间/强度；已有 Harvest State；天气与物候时间信息。
复用 V0.9 Management Event、Phenology Observation、PIT 架构，
不另建事件体系、不自动接农艺数据库、不读未授权记录、不预认定统计增益、
不训练完整生物机理生产模型。
交付价值假设、最小数据清单、现有缺口、下一阶段建议、候选最终研究结论。
结论限定 SUPPORTED_FOR_FURTHER_RESEARCH / NOT_SUPPORTED / INCONCLUSIVE / BLOCKED；
SUPPORTED 不代表生产批准。预计仅独立研究分析、合同及报告，不添加运行业务能力。
无合法 S3 证据不得借本阶段绕过未执行实验完成版本。

## 6. 完成定义与停止边界

VERSION_RESEARCH_COMPLETE 只有以下十项均满足才可 true：

1. S0–S4 按各阶段授权完成。
2. 算法研究合同清晰。
3. 至少一个真实可运行日曲线候选已实现。
4. S3 有合法可复核对照证据。
5. 数量与高峰指标分别评价。
6. 退化及无增益结果全部保留。
7. 原模型及历史证据不变。
8. PIT 与数据来源限制完整披露。
9. 研究结论及后续方向明确。
10. 最终版本审查完成。

研究可得 NO_STABLE_GAIN；没有执行不能算完成。
S3 数据权限 BLOCKED 时 VERSION_RESEARCH_COMPLETE=false。
即使完成仍保持 PRODUCTION_ACCURACY_VALIDATED=false、
PRODUCTION_DEPLOYMENT_AUTHORIZED=false，除非未来有独立充分验证及业务授权。
