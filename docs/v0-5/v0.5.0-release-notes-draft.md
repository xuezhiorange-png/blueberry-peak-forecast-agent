# v0.5.0 release notes draft

> Draft for Coordinator review. This document does not authorize a tag, GitHub
> Release, deployment, or production accuracy claim.

## What v0.5.0 adds

- Prediction is expressed at `BASE` grain, using the base's total productive
  area and base-level historical totals.
- The business season ends at the inclusive `04-15` cutoff.
- The active Base Registry contains 39 bases; the Yunnan-core weather research
  scope contains 38 bases.
- The operational product exposes the next complete 7-day and 15-day windows,
  each with total kg, peak date, and peak kg, plus a separate remaining-business-
  window result.
- Operational runs are immutable, idempotently created, canonically reloadable,
  and available through REST and CLI interfaces.
- The MCP surface contains nine tools: the existing area forecast tools plus
  `create_blueberry_operational_peak_forecast_run`,
  `get_blueberry_operational_peak_forecast_run`,
  `list_blueberry_operational_peak_forecast_runs`, and
  `get_blueberry_operational_peak_forecast_daily`.
- ERA5-Land historical/reanalysis data and a matched lagged-weather ablation are
  retained as research capability. They are not an as-issued forecast authority.

## Frozen operational policy

```ini
OPERATIONAL_PEAK_POLICY=OPERATIONAL_PEAK_POLICY_V1
SELECTED_BASELINE_ID=AREA_NORMALIZED_SEASON_WEEK_MEDIAN_V1
WEATHER_USED=false
W7=D+1...D+7
W15=D+1...D+15
PEAK_TIE_BREAK=EARLIEST_DATE
BUSINESS_CUTOFF=04-15_INCLUSIVE
```

The selected operational baseline is the area-normalized season-week reference.
The S4 weather experiment had mixed effects—some W15 diagnostics improved, while
daily performance did not improve uniformly and W7 peak-date performance
worsened—so a weather-aware operational model was not selected.

## Important limitations

This release is an operational product-path delivery, not a universal accuracy
approval. Full-season complete-label sample count is zero; a full-season total
yield model and season-peak model are not available. Point-forecast uncertainty
is not calibrated. Historical as-issued weather PIT is not established, and the
climate-zone mapping remains candidate-only (`DO_NOT_FREEZE_MAPPING`). Cross-zone
validation is not proven.

The v0.4 historical rolling-7-day metric should not be compared as if it were
v0.5's next-W7 forward window.
