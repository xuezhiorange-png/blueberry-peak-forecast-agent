## S1 — 生产周期特征构建（待独立授权）

- **业务目标**：用每季实际声明的周期起点表达事件时间，不假设所有基地同一天开季。
- **具体功能**：最薄 V0.20 package 输入桥、显式 cycle/member/primary-event 关联、三制度隔离、日期区间差计算、origin 可见性筛选、计划/观测分通道和原因账本。验证上游包/映射/词汇/文件 Hash，保持原始记录与修订，不反向改包。
- **代码范围**：建议 `backend/research/v021_cycle_features.py`；专项测试 `backend/tests/agronomic_history/test_v0_21_cycle_features.py`；`docs/v0-21/s1/` 说明及 evidence。只有纯离线关联/验证，不改前端解析器和现有 PIT/模型。
- **输入**：显式标识 SYNTHETIC_TEST_FIXTURE 的 V0.20 准备包；模拟权威成员及逐季主周期/主剪枝关系；timezone-aware origin/cutoff。上游 UNMAPPED 不能靠包 Hash 消除；演练需另外显式合成关系。
- **输出**：cycle/member 账本、日期精度/区间特征、origin 特征快照及 Hash、未关联/不可用原因。计划和实际各自输出，不能拼成实际观测。
- **合成测试场景**：至少两季不同起点、跨年/闰日、多基地/地块/品种、三个制度、缺促早、多次剪枝/主事件歧义、日/月/年精度、普通开花与百分比不混、UNKNOWN 方法、未知身份、晚到修订、D/未来扰动不变和合法 D−1 扰动可解释变化。
- **验收标准**：同输入同规范化 Hash；跨季锚点来自显式声明；区间差可手算；不清空坏记录；完整身份隔离；缺时钟证明不得进入严格 as-of 集合；产季峰/目标实际标签从未进入特征接口。真实 PIT 验证仍为 false。
- **禁止操作**：真实数据读取、填补农事日期、推断促早方法/生产制度、将经过日直接换算为成熟/产量、增添 Ridge 特征后偷偷拟合、修改 V0.20 数据或 V0.9 状态机。

## S2 — 生产结构变化与合成场景（待独立授权）

- **业务目标**：发现跨季品种投产面积、换苗和密植变化会使哪些研究输入不再可比，而非计算其产量增益。
- **具体功能**：跨季显式连续性映射；种植/投产/有效面积分别比较；品种退出/进入；换苗株群关联；有株数、测量面积和方法时给出密度描述；生成固定场景及关系差异/覆盖报告。S1 周期关系原样复用。
- **代码范围**：建议 `backend/research/v021_structure_scenarios.py`、对应 `test_v0_21_structure_scenarios.py`、`docs/v0-21/s2/` 及 evidence。可选研究侧补充声明只关联原包，不另建业务主数据或事件本体。
- **输入**：S1 合成周期包、两个以上产季面积版本、显式成员连续性和合成结构声明；V0.20 不存在的密度/换苗字段不得假称已采集。
- **输出**：逐成员前后结构、各口径面积差、退出/进入及冲突、场景 Manifest/Hash、不可比较原因。未知密度和换苗保持 null/NOT_PROVEN。
- **合成测试场景**：无变化；种植与投产面积分别变化；非重叠/冲突生效期；0 或缺失前值；换苗/品种替换；同地名不同实体；密度缺分母；跨基地/品种/制度隔离；未知连续性；顺序/版本改变的确定性检查。
- **验收标准**：原始数值、单位、来源、精度不变；不跨范围比较；有变化不等于冲突，有冲突不等于可覆盖；比例分母为 0 不产生无限值；所有场景预先登记；不输出产量因子/峰日偏移或模型胜负。
- **禁止操作**：新增真实来源、自动映射未知地块、补株数/有效面积、构造未经校准的农艺响应函数、调用评价结果选择更有利场景或改历史权威。

## S3 — 高峰与 7/15 日滚动评价准备（待独立授权）

- **业务目标**：在同一套明确成员、日历、数量口径和时点下，分别验收产季峰目标与任意起点滚动目标的评价输入。
- **具体功能**：预注册 comparison_family/C0；分离 origin 特征与标签接口；复用现有预测 seal、十指标算术和不可计算原因；核验完整季节曲线与 H7/H15 窗口；补最薄 rolling15 季节结构诊断；输出共同 Cm、分子/分母及限制。不训练或构造农艺增强预测器。
- **代码范围**：建议 `backend/research/v021_evaluation_readiness.py`、对应 `test_v0_21_evaluation_readiness.py`、`docs/v0-21/s3/` 及 evidence；不修改 `rolling_forecast/` 服务、原评分器/算法/模型。
- **输入**：S1/S2 合成包、显式合成日历/预测向量/独立成熟标签、固定来源和配置身份。可复用现有 synthetic 示例产生的曲线；不根据标签调整曲线。合成诊断不冒充农艺特征带来增益。
- **输出**：三评价族输入检查、单日/最大连续7日/15日窗口及窗口内逐日量、现有十指标 synthetic 算术、C0/Cm 与失败账本、因来源/时点/季节不全不能评价的清单。
- **合成测试场景**：完整与残缺季节、H7 前缀和 H15 局部峰不等于季节峰、两个等高峰最早并列、全零/缺日/重复日/负值、不足15日、跨实体/制度/产季/口径不混汇、后签发/晚到来源拒绝、标签扰动不影响特征封存、改善/退化/MIXED 都保留、不同 coverage 不虚称胜出。
- **验收标准**：H7/H15 日期精确，H7 是同 origin H15 前缀；季节 7/15 日峰遍历所有完整候选连续窗口并返回向量；S1 数学不变；新 rolling15 仅结构诊断；共同集及十指标不可计算分母规则与上游一致；完整季节未准入不计算季节总量 WAPE；空集不报 0 误差；H7 rolling7 起点 0 不报技能。
- **禁止操作**：真实预测/真实评分、以事后峰日作输入、对窗口标签归一化预测、修改原十指标/严格 PIT 门禁、混用模型族旧 WAPE、宣称精度提升或因果效果。

- **业务目标**：让后续数据责任人和研究人员知道哪些数据/关联/时点条件已经在合成中跑通、哪些真实证据仍缺失。
- **具体功能**：串联 S1→S2→S3 合成离线流程，形成可重复的只读报告和版本 Manifest；逐项列真实来源、成员、面积、周期、标签、时点和独立实验授权缺口；明确已实现、合成已验证、真实未验证。
- **代码范围**：建议 `backend/research/v021_readiness_report.py` 和最薄 `v021_readiness_cli.py`、`test_v0_21_readiness_report.py`、`docs/v0-21/s4/`、evidence 及版本收口说明；不建新网页/数据库/调度器。
- **输入**：S1–S3 已审核的合成产物、固定方案/源码/词汇身份、实际测试结果；不读取私有模型/采收或农事记录。
- **输出**：离线 `research-readiness.json`、`report.md`、`report.html`、`manifest.json`；可用/缺失/冲突覆盖和未来数据采集/公平研究建议。Hash 不包含机器时间或临时路径等非业务因素；运行时间另记。
- **合成测试场景**：完整多季链路、所有缺口/冲突组合、字段注入转义、两次独立进程同业务摘要、旧版本不覆盖、无网络/真实来源拒绝；报告区分结构通过与来源/模型未获批。
- **验收标准**：同一冻结输入可独立复核；报告指标可追溯；明确两个等优先级目标的就绪程度；无真实精度/因果/生产声称；S4 独立评审通过、Owner 授权合并及 main CI SUCCESS 后才记工程版本正式收口。Release/Deploy 仍未授权。
- **禁止操作**：自动开展真实数据研究、训练或模型晋级、把合成通过当作真实准确率、Release/部署、用本版收口冒称 V0.19/S3 真实目标全部完成。
