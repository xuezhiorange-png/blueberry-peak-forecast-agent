## 模型、时间与数量口径

默认研究基线只能显式引用已核验的 M0 全历史工件及登记 hash。
R1/R2 条件工件是诊断模型，ALL_HISTORY-SELECTED 文件名不具有批准效力。
当前没有 PRODUCTION_APPROVED 模型。本轮不训练、搜索或改变任何模型。

M0 数量口径为冻结业务窗口总量，默认研究窗口为 July-01 至次年 April-15，按已有季节轴推理。
拒绝把完整窗口总量归一化到剩余日期。FUTURE_SUBWINDOW_RESEARCH 暂不支持数量规则，不能隐式实现。
保持 ARRIVAL_EQUALS_HARVEST_EQUALS_MATURITY_PROXY；不是直接生理成熟观测。

真实发行必须有精确 Base、合法面积、产季、完整窗口及可核验授权来源，且系统实际发行时钟早于窗口开始。
caller 不能提供 issued_at。测试时钟只能产生 TEST_NOT_PROSPECTIVE 记录。
本地 hash 是内容身份校验，不是外部可信时间戳；文件系统管理员仍可改写文件，未宣称 WORM/外部公证。
真实请求尚未授权时 READY_NOT_ISSUED，不虚构下一季面积或管理事实。

## 保存与锁定评价

复用既有 CLI 的 m0-baseline 子命令、请求 schema、M0 推理、日历/Decimal/hash 和峰值指标。
数据库已有 run/import/evaluation 组件不改；本轮采用文件研究适配，不能宣称 PostgreSQL E2E。
每次发行、实际修订、重新评价均生成新 ID，记录 parent/supersedes，不原地更新旧记录。

实际输入保留业务日期、首次进入系统时间、源版本/hash、Base、单位、覆盖状态及修订原因。
字段为 new_quantity_kg；显式 OBSERVED/CONFIRMED_ZERO/MISSING，缺日不自动填零。
评分显式指定 seal_id、actual_snapshot_id、metric_contract_version，并验证工件和封存内容。
完整窗口结束且所有自然日合法覆盖后才能最终评分；临时实收不是整季验收。

指标冻结为总量/完整日/形状 micro-WAPE、P10/P50/P90 日期、单日峰和真正连续七日累计峰日期及数量、偏差及逐 Base 结果。
同曲线复算全部指标，合并 WAPE 加分子分母。零实际分母标记无定义。
METRIC_PROTOCOL_FROZEN=true；BUSINESS_ACCURACY_THRESHOLD_STATUS=NOT_ESTABLISHED。
评分不能自动重训、重选、修曲线或调整业务阈值。

## 验收与停止

本轮验收工程发行/封存/加载/实际版本/锁定评分/反向测试及干净目录审核包。
真实发报、未来实收、前瞻精度、概率校准、业务精度阈值、生产批准均独立登记。
没有未来实收时 PROSPECTIVE_ACCURACY_VALIDATED=false，等待真实证据，不由更多旧数据回测补齐。
保留旧 runner 身份限制、原工作簿未独立复核、六个 inner/一个 outer 数值缺口及独立审核未覆盖范围。
不追加模型实验、不改生产默认、不 commit/push/PR/Ready/Merge/deploy。
