## 目标与用户旅程

可信登录 → 查看自身授权范围 → 筛选并显式选择已保存预测 → 看预测起点后

可读取所有基地。完整身份、hash 或知道 run ID 都不是授权证明。

缺 child 不当零，不自动生成新的 hierarchy run 或使用当前 registry 改历史范围。

## 本版本范围 A：可信用户与资源授权

引入共享访问 Facade 的设计：认证、capability、资源 grant、canonical read、
hash/grant 复核、既有业务服务。HTTP 与 MCP 复用同一资源判定，计算仍用
V0.17 S1/S2 服务和 V0.16 引擎。旧粗粒度 actor 保留为 capability 的必要条件，
不能作为充分的资源级授权。没有 grant 默认拒绝，无 wildcard/allow-all。

最终用户 END_USER 与 SERVICE_ACCOUNT 分离，用户唯一键为可信 issuer + subject，
由受信任身份提供方验证后映射服务器内部 principal。名字、邮箱、source_system、
前端 actor 或任意 Header 不产生权限。推荐协议方向为 OIDC；具体提供方、
client 注册、账户映射、授权清单发布者必须在 S1 Owner 批准后绑定。
未配置时 fail closed；S0 不创建用户、凭据或权限数据库。

资源授权目录由受信任服务端发布，包含 principal 类型/ID、租户/组织边界、
capability、独立实体范围、季节、模型家族、准确 run identity/result hash、
授权 revision、生效/失效与撤销记录。BASE 范围不是 REGION/COMPANY 的权限；
aggregate 有独立明确 grant，授权发布者须确认聚合暴露的业务范围。反向也
不推断子节点权限。历史 Quality 需独立 model/split/season/scope grant。

未经授权不得查询敏感 run、日行、源链接、历史 Quality 文件或运行模拟。
可以读取隔离的授权策略/注册元数据，这是授权判定，不是业务 payload。
客户端请求无 grant（包括不存在的 run）一律固定 403，不确认其存在。
只有预先获准确 grant 后才允许 canonical lookup，授权指向的已删除记录可 404。
授予范围变化/撤销后每次请求重查，不靠过期浏览器上下文维持访问。

## 范围 B：有权限的保存记录发现和选择

新设计能力为 AUTHORIZED_SCOPE、AUTHORIZED_SAVED_RUN_LIST、VERIFIED_SELECTION_HANDOFF，
不是全局 latest。候选 URL/输入输出见 architecture 文档；本轮没有实现路由。
发现先在授权目录计算允许集合，再查询允许的最小保存记录元数据，最后分页。
不得先取所有 run 再由浏览器过滤；不得返回全局总数、越权实体名或被排除记录数。

列表返回完整 S1 identity + expected_source_result_hash，及经授权的实体显示名、
来源 family、origin、保存记录标识、completeness 与 rerun_of_run_id（仅另一个 run
也有授权时显示，否则隐藏）。不暴露每日数量或 private source paths。
origin_date 不冒充 as-issued_at；created_at 如显示须标记记录保存时间。

列表筛选 season、hierarchy、entity、family、origin 范围只能收窄授权集合。
稳定排序：origin_date DESC、source_kind ASC、forecast_family ASC、run_id DESC、
entity_id ASC、source_result_hash ASC。来源库间 run_id 不保证唯一，完整组合是 key。
keyset cursor 由服务器签名且绑定 principal/client、grant revision、目录快照、
filters/sort/last key/到期；不得靠 base64 隐藏来充当完整性保护。
默认 20、上限 100 条，cursor ≤2048 bytes/900 秒；无跨 principal 使用或全局 offset。
这些是拟定技术限制，不是已经验证的性能承诺。撤销、目录快照变更或过期要求重查。

选择交接由服务器签发短期绑定（300 秒），客户端不能任改 identity/hash；
交接不是 bearer 授权。服务器必须重验签名、principal/client、expiry/revision、
完整身份及 hash，再重做资源授权和 canonical read。请求过程中源漂移返回
409_RESELECT_NO_FALLBACK，不切换 latest、不选 rerun、不把旧 hash 自动更新。
选择成功后原子提交 Dashboard context；失败保持前一合法身份但清理冲突结果。

## 范围 C：Dashboard / MCP 业务流程

保留五页和八工具名称/业务 payload。授权封装和发现合同可新增，但不重写
权威数量、projection、adapter、engine、scenario 或 comparison hash。
新发现属于 HTTP 能力；不添加第九个 MCP 业务工具。AI 客户端通过受保护的
HTTP 发现/选择交接或服务器批准的 exact run context 获取身份，再调用八工具。
没有兼容的用户委托协议时只能使用明确的 service-account grant；必须显示
“服务账号范围”，不得宣称豆包最终用户隔离已经实现。

用户委托采用可信服务端/身份提供方签署的 token/context，不接受工具参数 actor。
有效权限为用户 ∩ client/service account ∩ exact run grants；任一不存在拒绝。
如何在客户端支持的协议上传输、撤销、audience 绑定须 S3 兼容验证。
协议不兼容是明确 blocker，不可静默回退成全账号权限。

运行绑定的 UPPER80、UPPER90、ATTRIBUTION、CHILD_CONTRIBUTION 继续
NOT_AVAILABLE。禁止 POINT fallback、加总 Base 上界、合成因素排名或浏览器
贡献比例。Point 不是已证明 P50，规划上界不是已校准分位数，模型贡献不是因果。
Quality 保留 M1 EXPOSED_OOT 2025–2026 历史聚合身份，不能随 run 换成当前准确率。
当前产季暂无可用于正式评分的实际采收数据。

情景输入显式 DIRECT / WORKFORCE_DERIVED、人效、同日 buffer、初始积压 0、
成本无默认；只有服务端返回积压、损失及条件排序。成本仍三个 synthetic contracts、
SYNTHETIC_LOSS_UNIT，不是人民币、节省/ROI、最佳排班或自动优化。
日期集合/成本/规划/hash 不同不比较，输入变化立即使旧结果和排名失效。

## 范围 D：独立安全试运行设计

仅设计隔离、合成环境，数据是显式 SYNTHETIC canonical saved runs；不连接
生产 DB、不挂生产域名、不实际部署。身份认证、授权目录、HTTP、独立 MCP、
Dashboard 入口配置可作为未来被授权的测试部署包。
HTTPS 默认强制，反向代理信任显式；Host/Origin allowlist 不代替认证。
浏览器不持有 MCP service secret；凭据用服务端 secret store，不能入 bundle、
URL、仓库或日志。旧 Trial/旧 MCP 路径不删除、不修改其历史合同，但安全试运行
入口必须默认网络拒绝，需实际证明受限客户端不能绕过新授权访问旧端点。

设计中包括只读业务期 DML guard、拒绝前零业务读取、脱敏审计、撤销/轮换、
backup/restore 的 identity/hash parity、故障/回滚及访问撤回演练。
审计只记 request ID、脱敏 principal/resource 标识、policy revision、结果 code、
时间及必要 hash，不记密钥/每日数量/实际采收。日志写入属于被授权的安全审计，
不等于经营动作；本轮没有执行它。RPO/RTO、留存/容量、运营负责人等待 Owner 决策。
