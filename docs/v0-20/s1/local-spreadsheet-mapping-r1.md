# V0_20 S1 — 本地电子表格准备操作

入口：现有 Dashboard → 预测 → 电子表格准备 → 历史农事数据。原入库与预测演示仍在相邻模式，切换时销毁当前 Worker 和页面内存，不创建新网站或上传接口。

1. 选 CSV/XLSX，或加载标明 SYNTHETIC 的两产季宽表、长表、冲突示例。原文件不被修改。
2. 选择工作表、实际表头行、数据类型和宽/长布局。中文/英文或非标准表头均人工选择列。可先检查任意字段，缺一列不会让整页空白。
3. 映射来源成员、产季、制度、计划/实际；展开来源/时间/修订字段。面积宽表分别选择三种面积列；长表选择口径和值。事件/物候宽表为每个日期列登记类型与状态，多个修剪列分别保存；长表用类型与业务日期列。
4. 加入当前表映射。相同文件可有多表，或一张表的三类映射；同表表头必须一致。合成建议仅填写列配置，不自动批准来源。
5. 规范化并检查。查看来源行、原因、三类台账、产季/基地过滤、时间线和静态报告。过滤只改变显示，不删导出记录。
6. 下载五文件或同名目录 ZIP。需要新映射时生成新版本，不覆盖原版本。旧版本只有通过明确选择才显示；更换文件或映射立即使当前结果失效。

## 宽长表约束

宽表可以一行含多次操作或阶段；每个槽位有稳定 ID、原列和声明类型。原始表头仍用于保护未知促早和普通开花含义。共用来源字段应用于该行；若不同操作的方法、时间或修订身份不同，应使用长表分别记录，不推断共享事实。

同一逻辑事实的修订需 explicit supersedes_revision。缺失、重复、循环或分叉只报告，不静默去重或选有效版本。面积重叠版本不相加；不同方法、样本、来源和计划/实际的物候不混合比较。

## 有界执行

复用原 Worker 安全解析器：文件 ≤2 MiB，ZIP 展开 ≤8 MiB，≤128 条目、8 张表、10,000 行、80 列、200,000 单元格、单格文本 ≤4096；预览最多50行。禁止公式、宏、外部链接和实体。Worker 本地解析预算8秒；规范化预算20秒；超限停止并提示拆分，不静默截断。

规范化 ≤20,000 条事实，五文件合计 ≤16 MiB；最多5个版本留在本页内存。表格/时间线/HTML 最多展示200条，JSON/CSV 保留所有行及异常。ZIP 在 Worker 压缩，主页面不同步处理大表。退出、清空或切换模式清除内存；无 localStorage 持久化，无网络上传。
