## 数据对象与结果

1. 品种和面积：种植、投产、有效面积独立；树龄/种植年、生效期、单位、来源版本保留。
2. 管理事件：一个地块可多次修剪、促早、开闭棚、加温或其他已有登记操作。计划、观测与未知独立；未知促早方式不推断加温/休眠解除。
3. 物候：开花开始/盛花/结束是 Production Plan 的普通阶段；明确 BLOOM_10/50/90 才使用相应注册状态，仍需方法、样本与质量说明。

每条记录保留文件 SHA256、工作表、原始行、原字段、列映射、来源编码、记录与修订身份、原始日期和精度。任意用户文件始终是 `USER_FILE_PREVIEW_UNVERIFIED`；本地准备不上传、不写生产数据库。只有原字节及解析内容同时与公开固定合成包一致，才能标记 `SYNTHETIC_TEST_FIXTURE`。

准备包为 JSON、面积/事件/物候三个 CSV 和静态 HTML；同输入和映射输出相同版本。状态可并存：`VALID_STRUCTURE`、`PARTIAL`、`CONFLICT`、`UNMAPPED`、`SOURCE_AUTHORITY_NOT_PROVEN`、`PIT_NOT_PROVEN`。结构通过不等于来源、训练或业务预测获批。
