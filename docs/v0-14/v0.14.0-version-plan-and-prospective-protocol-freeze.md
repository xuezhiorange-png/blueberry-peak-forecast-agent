## 天气捕获授权不是数量预测面积授权

天气可以比数量发报更早开始，不需要当季 harvest actual。天气坐标 authority
不等于 2026–2027 数量 scope authority。正式发报须有 target season、Base/farm identity、
当季 productive/planted/reference area authority、effective date/as_of 和 target window。
严格禁止 previous-season area fallback。

公开 persistence acceptance request 中存在保山杨柳农场 **393.4 亩**、target season
2026–2027、as_of=2026-09-12；这是 FIRST_ISSUANCE_SCOPE_CANDIDATE=YANG_LIU_2026_2027，
不是 FIRST_ISSUANCE_SCOPE_AUTHORIZED，也不证明本次已重新验证 current scope。
S3 需重新核验其 lineage；不能通过，可选其他确有合法 authority 的 scope。
无当季 authority 时天气捕获仍可在独立授权后进行，quantity issuance 必须 BLOCKED；
即使 engineering/weather ready，版本也不能伪造面积“完成”。

## Capture PIT 与不可变性

每次 accepted capture 必须 `issued_at <= fetched_at <= known_at <= forecast_created_at`，
违例 FAIL_CLOSED。选择 created_at 之前最新完整、已获资格的 provider run；不得未来 cycle、
回填 known_at 或用较新 run 追溯替换。保留 run id、issued_at、index bytes hash、
GRIB byte-range hashes、grid mapping、decoded values、manifest hash、fetched_at、known_at。
相同 run/path 的相同字节可复用；不同字节必须 conflict/fail closed。

Provider outage 记 WEATHER_CAPTURE_UNAVAILABLE；不能日后补抓新 run 冒充旧 origin。
缺失天气不是零；未预注册 interpolation 禁止。S0 不选择线性插值、carry-forward、
decay-to-climatology 或 ERA5 blend。如果 360h 不可靠，S1/S2 可以明确 H15 weather
feature NOT_AVAILABLE，不得强行推断；H15 harvest target 仍可存在，但 H8–H15 不能伪造
天气特征，具体可用 horizon 映射必须 S2 提前声明。

## 真正的 shadow 发报与 actual isolation

S3 的真实研究 issuance 为 TEST_ONLY=false、SHADOW=true、PRODUCTION=false。
同一 created_at、scope、window、area authority 同时输出 C0/W1，并立即 seal。
Seal 绑定 forecast_id、request snapshot、scope hash、两个 artifact hashes、天气 IDs/hashes、
provider manifest、created_at、prediction hashes 和 future metric contract。

预测 seal 前禁止 target actual read/score；target actual 若已进入模型选择、训练或
issuance decision，pristine 状态必须 INVALID_FOR_NEW_VALIDATION。隔离的是过程，
不是宣称能证明世界上不存在 actual。V0.14 不导入真实 target actual，不评分或选赢家。
