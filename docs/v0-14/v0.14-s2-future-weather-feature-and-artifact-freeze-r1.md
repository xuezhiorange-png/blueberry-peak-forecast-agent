## 信息边界与 feature contract

S1 证明 IFS instantaneous samples 与累计量的 native UTC steps 并不天然落在
Asia/Shanghai 日界线，因此本版不沿用 V0.13 local-day 聚合，不做 prorating、
interpolation、carry-forward、climatology 或 ERA5-to-live blend。

唯一 policy：`V0_14_RUNREL_168_360_WEATHER_R1`。anchor 为 provider issued_at，
time basis 为 `FORECAST_RUN_RELATIVE_UTC`。恰好两个非重叠 block：
`(0h,168h]` 和 `(168h,360h]`；不搜索其它窗口。

每个 block 按如下顺序提供四项，因此总共八项：

| 顺序 | Block | Summary |
|---|---|---|
| 1 | 0–168h | 2t duration-weighted endpoint sample，°C |
| 2 | 0–168h | tp168 × 1000，mm |
| 3 | 0–168h | ssrd168，J/m² |
| 4 | 0–168h | sqrt(u²+v²) duration-weighted endpoint sample，m/s |
| 5 | 168–360h | 2t duration-weighted endpoint sample，°C |
| 6 | 168–360h | (tp360 − tp168) × 1000，mm |
| 7 | 168–360h | ssrd360 − ssrd168，J/m² |
| 8 | 168–360h | sqrt(u²+v²) duration-weighted endpoint sample，m/s |

精确 feature names/order 见 machine-readable evidence。
instantaneous steps：3..144 每 3h，150..360 每 6h，共 84，排除 step0。
temperature/wind 使用 endpoint value × 距前一 step 的小时数，分别除以 168/192h。
这是 **native-step duration-weighted endpoint summary**，并非真实连续 time mean、
hourly mean 或 daily mean。累计 tp/ssrd 必须从 forecast start 起算，360 不得小于168；
不引入结果驱动 tolerance。SSRD 保留总能量，不转换平均 flux。
全程 Decimal precision=50，最后一次 quantize 到 12dp，ROUND_HALF_EVEN。

Tmin/Tmax 的 3h/6h interval extrema 与历史 hourly t2m 采样不具备完整语义等价，
本版排除。GDD 继续排除，没有隐藏 threshold 或 interaction。
W1 强制要求360h：缺失时 general 24/72/168 capture 仍可有效，但 W1 surface
不完整，C0/W1 pair 不得发报，不能复制168、零填或补历史天气。

## 工件 custody、确定性与 CI

两个独立新 Python processes、两个新 output directories，重新验证源身份、
构造 proxy、绑定同一 cohort 并 fit。feature policy、row/label、C0/W1 artifact、
bundle hashes 全部相同；7文件逐字节相同。源文件 hash/size/mtime 在每 run 前后不变。
scientific artifact body 没有 wall clock、随机UUID或绝对路径；acquisition receipt
与 scientific hashes 分离。重新加载 JSON 后在固定 non-label-bearing synthetic vector
上验证 prediction parity；不对历史真实行生成 prediction 或 score。

Private bundle 包含 feature policy、training cohort manifest、两个 artifact、historical
proxy manifest、live surface manifest 和 bundle manifest。每成员绑定name/SHA/size/role；
直接 self-hash 显式包含 standardization，不继承 V0.7 serializer gap。
S3 只有逐项 hash/schema/cohort/pair 核验后才能使用它；本轮不授权 S3。

公开只保存 counts、hashes、contracts 与状态，不包含 coordinates、天气值、
coefficients、training labels/keys 或 private paths。
Spreadsheet 读取遵循 frozen source parser，仅绑定已有训练 keys，未改写或导出原 workbook。
普通 CI 全部使用 synthetic fixtures，不读真实 private artifacts，不访问 ECMWF。
S2 focused tests 与 provider/PIT/S0/S1、area-yield 回归以及 ruff/format/mypy 必须通过；
最终 exact-head CI 状态由 PR 的 terminal run 单独验收，不等同于本地研究执行。
