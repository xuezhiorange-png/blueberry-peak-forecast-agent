`z_j = (float(x_j) - float(mean_j)) / float(scale_j)`

`c_j = float(beta_j) * z_j`

`raw = float(intercept) + sum(c_j in frozen feature order)`

An independent frozen-equivalent replay expression and the ordered attribution
sum must have identical binary64 representations. The clipped point is

Coefficients alone are not contributions: each contribution also depends on the
standardized input. A large raw input need not produce a large contribution.

## Postprocessing and exact accounting

Private contribution/intercept values use `.17g` round-trip binary64 text.
For negative raw scores, clip adjustment is `-raw`; otherwise it is zero.
Clipping is a separate postprocessing term, never distributed to features.

Serialization adjustment is the sealed Decimal prediction minus the sum of
serialized intercept, fourteen feature terms and serialized clip adjustment.
It accounts for binary64 arithmetic and decimal serialization residue, not a
business feature. Exact finite Decimal accounting uses sufficient local precision
for binary64 exponent ranges; public descriptive means/medians use precision 50.

`sealed point = intercept + feature terms + clip adjustment + serialization adjustment`

The final serialized accounting error must be exactly zero. Any sealed mismatch
fails the run; compatibility cannot be expanded to excuse numeric differences.

## Two independent grouping axes

FAMILY_GROUPING_R1 partitions features into BASE10 (first ten) and HARVEST_STATE
(last four). BUSINESS_SEMANTIC_GROUPING_R1 is a different partition:

- AREA: reference area only.
- SEASON_POSITION: progress and four harmonics.
- AREA_SEASON_INTERACTION: four area × harmonic terms.
- HARVEST_STATE: four frozen harvest-state terms.
- OTHER: reserved and empty; unknown features fail schema validation.

Within each axis every feature occurs exactly once. Axes cannot be mixed into
one additive partition: BASE10 must not be added again to AREA/SEASON_POSITION.
Interaction contributions remain joint model terms, not separately attributable
area or season effects. Harvest State terms are not evidence that past harvest
caused future changes. Magnitude ranking, if shown, is only
MODEL_SPACE_MEAN_ABSOLUTE_CONTRIBUTION_RANK, not business or causal importance.

## H7/H15 attribution

Per-origin H7 sums D1–D7; H15 sums D1–D15. Sealed point totals, every feature
term, both group axes, intercept, clip and serialization adjustments are summed
from daily attribution. The intercept total equals the serialized intercept
times horizon day count. Both complete horizons must reconcile exactly.
This is not a new H7/H15 model. Generic incomplete horizons are explicitly not
computable and never padded with zero. Real frozen input requires fifteen days
for every admitted origin.
