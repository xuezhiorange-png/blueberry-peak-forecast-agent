## Pre-execution mathematical policy freeze

The following R1 rules and explicit synthetic fixture are frozen before running
acceptance. No scenario/weight/group is selected after observing results.

Policies: V0_16_WHAT_IF_DECISION_SIMULATOR_R1,
V0_16_EXPLICIT_DAILY_HANDLING_CAPACITY_R1,
V0_16_DETERMINISTIC_BACKLOG_BALANCE_R1,
V0_16_PLANNING_DEMAND_VS_CAPACITY_LOSS_R1,
V0_16_SAME_FORECAST_PLANNING_LEVEL_COST_CONTRACT_R1,
V0_16_CONDITIONAL_SCENARIO_RANKING_R1.

Input is an immutable saved forecast for one BASE/REGION/COMPANY entity.
FARM/FACTORY are not hierarchy levels. No aggregation, forecast inference,
calibration, labels or actual matching occurs. Caller-supplied Region/Company
curves require their own saved authority; Base uncertainty bounds are not summed.
POINT is not proven P50. UPPER_PLANNING_BOUND_80/90 are not quantiles.
Any missing selected bound blocks the scenario, with no fallback or zero fill.
Dates are unique, continuous natural days; capacity dates must match exactly.

DIRECT requires explicit nonnegative Decimal capacity and null workforce fields.
WORKFORCE_DERIVED requires explicit integer workforce and Decimal productivity,
both nonnegative; direct capacity must be null. No hidden productivity.
Buffer is SAME_DAY_ADDITIVE_HANDLING_CAPACITY, not cold-storage inventory.
Absent buffer is explicitly buffer_supplied=false / zero; unused buffer never
carries forward. No inventory, routing or automatic peak shaving is inferred.

Let D be selected demand, H handling, B buffer, C=H+B and Q opening backlog.
INITIAL_BACKLOG_KG=0. Each day:

`workload = Q + D; processed = min(workload,C); closing = workload-processed`.

`Q + D = processed + closing`; next opening equals previous closing.
Daily overload = max(D−C,0), over-capacity = max(C−D,0).
Cumulative shortfall is sum(daily overload), NOT ending/max backlog.
Max backlog is max(closing); ending backlog is the last closing value.
Gross capacity surplus is not actual idle capacity because backlog may consume it.
