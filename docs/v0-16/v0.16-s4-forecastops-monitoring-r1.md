production alert system: forecast → exact actual matching → maturity and
completeness gates → locked scoring → descriptive quality monitoring.

## Matching, maturity and completeness

Forecast slots bind exact Base, season, timezone-aware origin, frozen model and
source policy. Targets must be D1–D15, date = origin local date + lead, unique,
complete, finite and nonnegative Decimal quantities. Exact Base/date matching
never uses nearest dates, fill-forward, seasonal allocation or zero imputation.

Actual states are CONFIRMED_QUANTITY, CONFIRMED_ZERO and MISSING. Confirmed zero
is complete evidence. Missing is not zero; PARTIAL and EMPTY are not COMPLETE.
For each origin/horizon, maturity requires evaluation local date **strictly
after** the horizon's final target date. Future targets are NOT_MATURED, not
missing-data failures. No implicit clock is used.

Real acceptance supplies deterministic research-only evaluation-as-of:
max(frozen target date) + one calendar day, at local midnight Asia/Shanghai.
This proves date maturity only, not historical actual availability at that time.

Scoring requires matured + forecast complete + actual complete + integrity PASS.
Aggregate metrics may use COMPLETE cells while other cells are PARTIAL, but
every horizon exposes expected/issued/matured/not-matured/forecast-complete/
forecast-partial/actual-complete/partial/empty/scorable/not-scorable counts.
Origin scoring coverage = scorable / matured; actual target completeness =
present actual target rows / expected matured actual target rows. These are
different quantities, and neither conceals excluded cells.

No matured origins means INSUFFICIENT_DATA. Matured but none scorable means
NOT_SCORABLE. A nonempty explicitly complete scoring subset means SCORABLE,
not that the entire cohort is fully complete.

## Locked scoring contract

H1/H3/H7/H15 are **prefixes D1 through DH**, not individual D3/D7/D15 leads.
Separate exact-lead D1/D3/D7/D15 metrics are also emitted.
Arithmetic uses Decimal under a local precision of 50; there is no float
accumulation or six-decimal internal display quantization.

Error sign is forecast − actual: positive Bias means overforecast.

- Daily WAPE = sum absolute daily error / sum actual.
- Daily MAE kg = sum absolute daily error / comparable daily row count.
- Daily Bias kg = sum signed daily error / comparable daily row count.
- Cumulative WAPE = sum across origins of absolute horizon-total error / sum
  horizon actual totals. Cancellation inside one origin is retained.

Zero actual denominators give null WAPE/cumulative WAPE with
NOT_COMPUTABLE_ZERO_ACTUAL_DENOMINATOR, not zero. MAE and Bias still compute on
complete zero-actual cells. Zero origins are never removed to manufacture WAPE.

Real H7/H15 daily WAPE, H7/H15 cumulative WAPE, H15 MAE and H15 Bias must equal
the committed V0.15 S5 M1 strings exactly. Any disagreement stops acceptance.
H1/H3 are new descriptive monitoring outputs, not result-driven method changes.

## Integrity, readiness, trend and runtime observability

Independent status axes are INTEGRITY_STATUS, SCORING_READINESS and
QUALITY_TREND. Model/policy/source/hash mismatch is SOURCE_DRIFT; malformed
calendar/quantity/interval schema is SCHEMA_DRIFT; duplicate targets are
ROWSET_INTEGRITY_FAILED; duplicate issuance is DUPLICATE_ISSUANCE. Invalid
integrity yields NOT_SCORABLE and no quality values even if apparent error is low.
Poor accuracy alone does not imply integrity failure.

Without a comparable explicitly supplied reference snapshot, trend is
NO_REFERENCE. Scope, metric policy, source forecast identity, expected universe
and horizons must match. The four lower-is-better primary metrics are daily
WAPE, MAE, absolute daily Bias and cumulative WAPE. All equal → UNCHANGED;
all no worse with one improvement → IMPROVED; all no better with one worsening
→ OBSERVED_DEGRADATION; mixed directions → MIXED.
