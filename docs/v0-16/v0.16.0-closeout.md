### E. Business Loss

S5 冻结：

`BusinessLoss = C_under * max(actual - forecast, 0) + C_over * max(forecast - actual, 0)`。

显式 immutable cost authority、Decimal-only arithmetic、同 cost contract/
actual authority/完整 common origin-prefix rowset 的公平比较已建立。
Acceptance 只使用三个 EXPLICIT_SYNTHETIC_SCENARIO：1:1、4:1、1:4，
单位 SYNTHETIC_LOSS_UNIT。真实冻结 historical quantity × synthetic cost weights
是 SYNTHETIC_BUSINESS_LOSS_EXPERIMENT，**不是公司真实财务损失、节省或 ROI**。

### F. What-if Decision Simulator

S6 对 saved forecast、明确 planning level、explicit capacity/buffer/cost
作 deterministic scenario evaluation。DIRECT 或 WORKFORCE_DERIVED
（workforce_count × 显式 productivity），无隐藏生产率。
Buffer 是 same-day additive handling capacity，不是库存，不跨日结转。
Initial backlog=0；opening + demand = processed + closing，
processed=min(opening+demand,effective capacity)，次日 opening=前日 closing。
Daily overload=max(new demand−capacity,0)，累计 shortfall 是其和，
不等于 max/ending backlog。Utilization 使用 processed/capacity；精确 authority
是 numerator/denominator pair，仅 daily/aggregate 派生表示允许 Decimal50
ROUND_HALF_EVEN，rounded utilization 不进入 capacity、loss 或 ranking。
S5 kernel 映射 planning demand vs effective capacity，属于 planning-gap loss，
不是 actual-vs-forecast scoring，也不计 backlog aging cost。
比较必须同 forecast/hierarchy/planning level/date set/cost contract；仅对显式
提交的 scenarios 排序。不是 optimizer、capacity search、workforce scheduling、
routing、automatic peak shaving 或 automatic execution。
冻结 synthetic acceptance 为 3 planning levels × 3 costs × 3 scenarios =
27 runs / 9 independent comparison groups，B/C equivalent-capacity parity PASS。
