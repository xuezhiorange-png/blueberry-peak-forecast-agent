# Purpose: pin direct project dependencies so CI runs are reproducible
# across PRs. This file is the SINGLE source of truth for CI install —
# invoked via:
#     pip install -c backend/constraints-ci.txt -e ".[dev]"
#
# Scope discipline:
# - Only the direct deps declared in pyproject.toml are pinned.
# - Versions are EXACT pins (``==``) because the floors in pyproject.toml
#   are already permissive (``>=``) and a single PR should not silently
#   pull in newer minor versions.
# - No broad dependency upgrades are introduced.
# - Transitive deps (numpy / scipy / anyio / …) are NOT pinned here —
#   they are resolved through pip's resolver and locked indirectly by
#   the direct pins above.
#
# If a future PR needs to bump one of these, the bump must:
#   (1) update this file,
#   (2) update pyproject.toml's ``>=`` floor to match,
#   (3) be exercised in a canary run before merging.
